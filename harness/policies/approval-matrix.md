# 승인 매트릭스

| 작업 | AI | 사람 | 자동 게이트 |
|---|---|---|---|
| 요구사항 질문과 초안 | 수행 | 결정 | Issue Form |
| Issue 확정 | 제안 | 승인 | `status:ready` 검사 |
| 조사, 계획, 구현 | 수행 | 필요 시 답변 | 작업 브랜치 검사 |
| 테스트와 리뷰 | 수행 | 최종 검토 | 품질 검사 |
| Draft PR 생성 | 수행 | 확인 | PR 계약 검사 |
| PR 최종 승인과 머지 | 수행하지 않음 | 수행 | Ruleset |
| 시크릿 접근 | 수행하지 않음 | 수행 | Codex 훅 |
| 파일과 데이터 삭제 | 수행하지 않음 | 수행 | Codex 훅 |
| 데이터 마이그레이션 | 수행하지 않음 | 수행 | Codex 훅 |
| 배포 | 수행하지 않음 | 배포 담당자 | 별도 CI/CD |

Migration은 데이터베이스 스키마나 저장 데이터의 구조와 값을 바꾸는 실행을 뜻한다. 마이그레이션 코드 작성과 테스트는 Issue 범위에 포함될 수 있지만 실제 환경 적용은 사람이 수행한다.
