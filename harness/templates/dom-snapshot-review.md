# DOM 스냅샷 수집·검토 기록 양식

이 파일은 복사해 사용하는 **빈 양식**이다. 실제 수집·비식별화·검토가 끝났다는
근거가 아니다. 원본 HTML, 실제 값, URL, 원본 식별자 대응표, Console, 스크린샷을
붙이지 않는다. [수집 정책](../policies/dom-snapshot-fixtures.md)을 먼저 따른다.

## 대상과 승인

| 항목 | 기록 |
| --- | --- |
| 픽스처 ID / 공개 site_id / Issue 번호 | |
| 사람이 지정한 최소 영역과 준비한 상태 | |
| 이번 수집 요청 확인 | 미확인 |
| 수집일 | 미수집 |
| 출처 종류 | 미확인: 직접 정제한 스냅샷 / 관찰 후 합성 재현 |
| 설치 제품 revision / 확인 방법 | UNVERIFIED / 미확인 |

출처 종류를 확정하지 못하면 실제 스냅샷이라고 등록하지 않는다.

## 출력 전 검토

- [ ] 사람이 공통 양식 텍스트와 최소 범위를 브라우저 안에서 검토했다.
- [ ] 도구가 원본 DOM·접근성 트리·Console·네트워크·화면을 자동 보관하지 않음을 확인했다.
- [ ] 원본은 변경하지 않고 새 비활성 문서에 허용 정보만 옮긴다.
- [ ] value/defaultValue, textarea/contenteditable 본문, 선택·체크 상태를 제거한다.
- [ ] 라벨·설명·placeholder·ARIA·title·alt의 개인화 정보를 제거한다.
- [ ] 숨김 필드, data 속성, 주석, 내장 JSON, URL과 파일 경로를 기본 제외한다.
- [ ] 스크립트·handler·srcdoc·외부 CSS/리소스를 제거한다.
- [ ] 미검토 정보와 오류 원문이 반환되지 않는다. 불확실하면 중단한다.
