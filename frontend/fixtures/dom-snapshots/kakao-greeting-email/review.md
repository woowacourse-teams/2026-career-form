# DOM 스냅샷 검토 기록: kakao-greeting-email

**최종 판정: 보류.** 실패를 관찰한 Kakao Games Greeting에서 다시 수집했지만, 정적 샘플로는 평가에서 관찰한
실패가 재현되지 않았다. [수집 정책](../../../../harness/policies/dom-snapshot-fixtures.md)에 따라 재현되지 않은
샘플은 테스트로 등록하지 않는다.

초기 샘플은 실패 관찰 사이트가 아닌 Kakao Mobility Greeting에서 발췌했다. 이번 재수집으로 관찰 사이트와 수집 사이트가 같아졌다.

## 실패 조건과 코드 경로

- 오류 문구 `이메일주소 선택을 안전하게 적용하지 못했습니다`는 `workflow-analysis.ts`에서 어댑터에
  `stateDriverStage`가 있고 쓰기 결과가 `written`이 아닐 때 표시된다.
- `skipped` 후보 조건은 라벨 변경, 중복 컨트롤, 기존 값, 매핑 미확인, 읽기 전용, 페이지의 값 거부다.

## 출력 전 검토

- [x] 추출 규칙과 일회성 추출 코드를 실행 전에 사용자가 승인했다. LG 규칙에 Greeting 상태 속성 처리(data-state, data-value, aria-checked·aria-selected, data-placeholder 계열, data-view·aria-activedescendant)를 더했다.
- [x] 원본은 변경하지 않고 새 비활성 문서에 허용 정보만 옮겼다.
- [x] 입력값과 같은 텍스트 11곳을 [TEXT]로 바꿨다.
- [x] 실패 시 종류만 반환하고 정제 결과는 파일로만 저장했다. 대화에는 통계만 출력했다.
- [ ] 도구가 원본 DOM·Console을 자동 보관하지 않는지는 확인하지 못했다(Aside REPL 세션 보관 정책 미확인).

## 재수집 전후 비교

| 대상       | 초기 샘플(Kakao Mobility 발췌) | 재수집본(Kakao Games 전체)                           |
| ---------- | ------------------------------ | ---------------------------------------------------- |
| 회사 판정  | generic                        | greeting                                             |
| 수집 후보  | 2개                            | 89개(섹션 32개, 반복 묶음 4개 포함), 라벨 문맥 82개  |
| 이메일주소 | 범용 경로에서 written          | Greeting 워크플로 전체 실행에서도 written, 예외 없음 |

초기 판정 "정적 구조에서는 정상 입력"은 Greeting 어댑터를 거치지 않은 결과라 근거가 되지 못했다.
재수집본은 Greeting 경로를 거치고도 같은 결론이므로, 실패 원인이 정적 구조 밖에 있다는 판단의 근거가 더 강해졌다.

## 오프라인 관측

| 단계      | 결과                                                                                                                                      |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 수집      | 이메일주소는 `basicInformation.email`. 입력란은 type=text, role=combobox, data-scope=combobox, data-part=input, 같은 필드 루트에 버튼 1개 |
| 검토 계획 | `available`                                                                                                                               |
| 실행      | `written`, 입력란 값 설정됨, 예외 없음                                                                                                    |

편집 명령과 이메일 확인 버튼의 활성화 같은 페이지 반응은 테스트 유틸이 대신하거나 재현하지 않았으므로
**페이지가 값을 거부하거나 확인 절차를 요구하는 경우는 검증하지 못했다.**
