# DOM 스냅샷 검토 기록: naver-panel-loss

**최종 판정: 수집 중단.** 실패가 특정 필드 구조가 아니라 분석 중 확장 패널이 사라지는
동적 현상이라 정적 DOM 샘플로 재현할 수 없다.

## 관찰

- 평가에서 분석을 시작한 뒤 페이지 내부 패널 호스트가 DOM에서 사라지고 완료 이벤트를 받지 못했다.
- 이후 페이지는 `readyState=complete`였고 시작 버튼은 남아 있었으며, 일부 입력란에 기본값이 있었다.
- 기준선과 PR 빌드에서 모두 관측되었다. 어느 쪽 변경과도 연결되지 않는다.

## 수집하지 않은 이유

| 조건                                   | 판단                                                     |
| -------------------------------------- | -------------------------------------------------------- |
| 실패가 필드 구조에 의존하는가          | 아니다. 패널 생명주기(마운트·제거) 문제다                |
| 정적 HTML에 필요한 동작이 있는가       | 없다. 제거 시점과 원인 이벤트가 DOM에 남지 않는다        |
| 원본에 없는 이벤트를 추가해 재현하는가 | 하지 않는다. 합성 동작을 실사이트 사실로 주장하지 않는다 |

기존 `entrypoints/autofill.content/index.test.tsx`의 패널 생명주기 테스트 6개는 통과하며,
평가 중 현상은 이 테스트가 다루는 경로 밖에 있다.

## 후속 후보

- 패널 호스트가 제거되는 시점과 원인(SPA의 DOM 교체, 컨텍스트 무효화, 제거 이벤트)을 구분하는
  비식별 진단을 먼저 확보한다. 진단이 없으면 어떤 샘플도 근거가 되지 않는다.
- 제품 수정은 이 작업의 범위가 아니다. 별도 Issue로 제안한다.
