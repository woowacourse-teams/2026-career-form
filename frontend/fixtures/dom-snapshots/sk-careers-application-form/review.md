## 출력 전 검토

- [x] 추출 규칙과 일회성 추출 코드를 실행 전에 사용자가 승인했다.
- [x] 원본은 변경하지 않고 새 비활성 문서에 허용 정보만 옮겼다.
- [x] value, textarea 본문, 선택·체크 상태를 제거했다.
- [x] type=hidden 입력란, data 속성(허용한 소문자 토큰 제외), 주석, URL을 제외했다.
- [x] script, handler, style, 이미지를 제거했다.
- [x] 실패 시 종류만 반환하고 정제 결과는 파일로만 저장했다. 대화에는 통계만 출력했다.
- [ ] 도구가 원본 DOM·Console을 자동 보관하지 않는지는 확인하지 못했다(Aside REPL 세션 보관 정책 미확인).

## 재수집

첫 샘플은 반복 행을 추가하지 않은 상태(컨트롤 59개)에서 수집해 학력·경력 칸이 없었다. 사용자가 반복 행을 종류별로 하나씩 추가한 뒤 같은 규칙으로 다시 수집해 교체했다.
