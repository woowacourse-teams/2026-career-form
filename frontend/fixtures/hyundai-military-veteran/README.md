# 현대 병역·보훈 fixture 조합

기준: `../profile-export.hyundai.example.json` 전체 프로필. 이 디렉터리의 파일은 병역·보훈 시나리오만 바꾸며 나머지 프로필 영역은 기준 fixture와 동일하다.

보훈 대상 fixture와 기준 프로필의 `veteranNumber`는 현대 `branchNo` 계약(숫자만, 최대 10자리)에 맞춘 합성 테스트값 `1234567890`이다. 보훈 비대상 시나리오는 관계·번호 없이 상태만 유지한다.

| 병역 시나리오 | 현대 선택 후보          | 조건부 상세                     |
| ------------- | ----------------------- | ------------------------------- |
| 군필          | 필/1                    | 육군/1, 병장/41, 시작·종료 연월 |
| 미필          | 미필/2                  | 상세 미입력                     |
| 면제          | 면제/5                  | 신체문제/01                     |
| 비대상        | 비대상(여성/해외국적)/7 | 상세 미입력                     |

| 보훈 시나리오 | 현대 선택 후보 | 조건부 상세              |
| ------------- | -------------- | ------------------------ |
| 대상          | 예/Y           | 본인/1, 숫자 10자리 번호 |
| 비대상        | 아니오/N       | 관계·번호 미입력         |

실제 DOM/설치 검증 상태는 [기존 Draft PR #84의 검증 기록](https://github.com/woowacourse-teams/2026-career-form/pull/84)에 게시한다. 제출·저장·임시저장 근거로 사용하지 않는다.

## 만기전역 alias fixture

[별도 만기전역 fixture](../profile-export.hyundai.military-completed.example.json)는 기존 현대 전체 fixture를 그대로 복사하고 `profile.military.militaryStatus`만 `만기전역`으로 바꾼다. 다른 프로필 범주와 병역·보훈 상세값은 변경하지 않는다. 이 파일은 회사·프로필 필드 키 한정 normalization의 구조 경로 확인용이며, 실제 설치 재진입·저장·제출 성공을 주장하지 않는다.

## 공통 장애 테스트값

모든 JSON fixture는 기준 프로필과 동일하게 장애 여부 `대상`, 유형 `지체장애`, 정도 `중증`을 포함한다. 등록번호 `DIS-DEMO-001`과 등록일 `2020-01-01`도 가져오기·내보내기 확인용 합성 값이다. 실제 개인정보가 아니며 지원서에 제출하면 안 된다. 등록번호·등록일의 존재가 해당 사이트의 자동기입 지원을 의미하지는 않는다.
