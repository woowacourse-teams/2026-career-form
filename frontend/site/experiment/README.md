# 세 조건 패널 대기 경험 실험

현재 버전은 `panel-study-v18`이다. 이전 응답과 섞지 않고 세션도 새로 시작한다.

- A 완료 작업형: 완료한 입력 항목 수만 표시.
- B 진행률형: 전체 입력 완료 비율과 로딩바.
- C 남은 작업형: 실제 남은 입력 항목 수만 표시.

세 조건은 동일한 132px 캐릭터와 흔들림 애니메이션, 위치, 공통 문구 “지원서를 채우고 있어요”, 40개 예제 입력 및 6615ms 타임라인을 사용한다. 감소 모션 설정에서는 모두 정지한다. 별도 애니메이션 조건 D는 제거했다.

가설: 완료 작업 수 대신 진행률 또는 남은 작업 수를 보여주면 더 편안하게 기다리면서 신뢰도 유지된다.

10명 모두 세 조건을 체험한다. 순서는 ABC, ACB, BAC, BCA, CAB, CBA를 지원하며 `?order=ABC`처럼 지정한다. 10명은 모든 순서에 1명씩 배정한 뒤 네 순서에 1명씩 추가 배정해 순서 편향을 줄인다. 이전 AB/BA 링크는 지정 배정에 사용하지 않는다.

각 체험 후 편안함·신뢰감·체감 대기 시간을 1~5점으로 평가한다. 마지막에는 세 화면과 ‘차이 없음’ 중 선택한다. 성공은 B 또는 C 중 동일한 대안 하나가 A 대비 편안함 평균 +0.5점 이상, 신뢰감 차이 0점 이상, 최종 선호 10명 중 5명 이상을 모두 만족하는 것이다. 동일 조건으로 10명이 완료하지 못하거나 실행 오류가 있으면 판정 불가다. 세 조건을 모두 만족하지 못하면 이번 실험에서 가설을 지지하지 못한 것으로 기록한다.

실제 지원서 제출이나 서비스 API 호출은 없다. 예제 데이터만 사용하고 응답은 브라우저 세션에 저장하며 전달용 JSON 파일을 내려받는다. 중앙 응답 수집은 아직 구현하지 않았다.

범주별 기록은 제거했다. 세 조건은 동일한 공통 컴포넌트에서 라벨·숫자·단위만 바꾸며, B에만 진행 바를 표시한다. 정보 영역 높이, 숫자 크기(48px), 위치, 여백을 동일하게 유지한다.
