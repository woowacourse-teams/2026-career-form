# 두 조건 패널 대기 경험 실험

현재 버전은 `panel-study-v15`이다. 이전 응답과 섞지 않고 세션도 새로 시작한다.

- A 작업 내역형: 처리한 범주와 입력 개수.
- B 진행률형: 전체 입력 완료 비율과 로딩바.

두 조건은 동일한 132px 캐릭터와 흔들림 애니메이션, 위치, 공통 문구 “지원서를 채우고 있어요”, 40개 예제 입력 및 6615ms 타임라인을 사용한다. 감소 모션 설정에서는 모두 정지한다. 별도 애니메이션 조건 D는 제거했다.

가설: 작업 내역 대신 진행률을 보여주면 더 편안하게 기다리면서 신뢰도 유지된다.

10명 모두 두 조건을 체험한다. 조사자가 5명에게 `/experiment/?order=AB`, 나머지 5명에게 `/experiment/?order=BA`를 전달한다. 기본 링크의 무작위 배정만으로 5:5를 보장하지 않는다. 지정 링크에서는 해당 순서와 일치하는 현재 버전 세션만 복원한다.

각 체험 후 편안함·신뢰감·체감 대기 시간을 1~5점으로 평가한다. 마지막에는 두 화면과 ‘차이 없음’ 중 선택한다. 성공은 B가 A 대비 편안함 평균 +0.5점 이상, 신뢰감 차이 0점 이상, 최종 선호 10명 중 5명 이상을 모두 만족하는 것이다. 동일 조건으로 10명이 완료하지 못하거나 실행 오류가 있으면 판정 불가다. 세 조건을 모두 만족하지 못하면 이번 실험에서 가설을 지지하지 못한 것으로 기록한다.

실제 지원서 제출이나 서비스 API 호출은 없다. 예제 데이터만 사용하고 응답은 브라우저 세션에 저장하며 전달용 JSON 파일을 내려받는다. 중앙 응답 수집은 아직 구현하지 않았다.
