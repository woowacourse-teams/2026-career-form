# LLM Wiki 정본 우선과 수집 승인

## 상태

승인됨

## 날짜

2026-08-18

## 관련 Issue

- #25

## 배경

제품 원칙, 프로필 기준, Issue와 하네스 규칙이 여러 정본 문서에 나뉘어 있다. 이를 빠르게 탐색할 Wiki가 필요하지만, 요약이 정본을 대체하거나 대화·개인정보를 자동 수집해서는 안 된다.

## 검토한 대안

- 대화와 저장소 문서를 자동 수집한다: 승인 경계와 개인정보 보호 원칙을 지키기 어렵다.
- Wiki를 두지 않는다: 작업 전 정본 탐색 비용이 계속 반복된다.
- 사람이 요청한 정본 발췌와 승인된 후보만 수집한다: 탐색성·통제·보존 원칙을 함께 지킨다.

## 결정

`llm-wiki/raw/`에는 비식별 원본 스냅샷을 추가 전용으로 보관하고, `llm-wiki/wiki/`에는 raw 근거를 링크한 최신 요약을 둔다. 정본과 Wiki가 충돌하면 정본을 우선한다. 사용자가 명시적으로 요청한 수집은 즉시 수행하고, 에이전트가 발견한 자료는 후보와 이유를 먼저 제시해 사람 승인을 받는다.

## 결과

팀원과 에이전트는 색인에서 제품·기술·컨벤션 맥락을 찾을 수 있다. 자동 검증은 Wiki 경로, 메타데이터, raw 근거와 색인을 검사한다. 대화 전문, 실제 지원 정보, 계정·세션·시크릿은 수집 대상이 아니다.
