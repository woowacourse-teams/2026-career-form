# 프로젝트 지식 안내

프로젝트의 제품 기준, ADR, 설계, 계획, 조사와 운영 문서는 LLM Wiki로 이전했다.

- 현재 상태와 주제별 이력: [Wiki index](../llm-wiki/wiki/index.md)
- CF-41 이전 문서 현재본: [docs baseline](../llm-wiki/wiki/topics/docs-baseline.md)
- Issue별 불변 근거: [`llm-wiki/raw/issues/`](../llm-wiki/raw/issues/)

신규 구현 계획은 `git rev-parse --git-path cf-workflow/plan.md`가 반환하는 worktree별 Git 메타데이터에 기록한다. 이 디렉터리에는 새 활성 문서를 추가하지 않는다.
