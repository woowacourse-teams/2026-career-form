# 제품 안전 원칙

> Source: docs/PRODUCT_CONCEPT.md
> Collected: 2026-08-18
> Published: Unknown

사용자가 직접 등록하고 관리한 지원 정보를 필요한 시점에 안전하게 재사용하도록 돕는다.

자동 입력 전에 대상 항목과 입력 예정 값을 보여주며, 사용자가 명시적으로 선택하고 승인한 항목만 변경한다. 이미 값이 있는 필드는 기본적으로 덮어쓰지 않는다.

확장 프로그램은 지원서 저장 버튼, 다음 단계 버튼, 최종 제출 버튼을 조작하지 않는다. 사용자 정보는 브라우저 로컬 저장소에 보관하며 MVP에서는 외부 서버로 전송하거나 동기화하지 않는다.
