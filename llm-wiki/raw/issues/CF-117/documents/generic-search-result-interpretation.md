# 공급자 중립 검색 결과 구조 해석 경계

근거: [Issue #117](https://github.com/woowacourse-teams/2026-career-form/issues/117), 기준 revision `e8528155bce7859917a0f78059ddea8a8de08edb`의 작업 브랜치 CF-117.
CF-129까지의 범용 검색 계약은 유지한다. 이 문서는 기존 결정적 검색이 결과 구조만 해석하지 못한 경우에 OpenAI와 Jev가 공통 계약으로 결과 구조의 유한 역할만 판정하고, 브라우저가 결과 데이터를 로컬에서 비교해 원본 요소를 한 번 클릭하는 경계를 추가한다.

## 승인된 후보 전체

1. CF-117은 검색 결과 컨테이너·항목·선택 동작의 유한 역할과 구조 metadata를 OpenAI/Jev 공통 계약에 추가한다. 결과 역할에는 semantic label을 허용하지 않고 결과 데이터·handler 원문은 브라우저에만 둔다.
2. 공급자 후보는 개별 정답 행이 아니라 전체 결과 행에 공통으로 적용할 구조를 뜻한다. 동일 구조의 행 집합을 로컬에서 재검증하고 전체성 근거와 정확한 단일 일치, 별도 활성화 근거를 만족할 때만 원본 요소를 한 번 클릭한다.
3. 새 구조 경로는 기존 정적·CJ·결정적 검색 뒤에만 사용한다. 선택 효과는 표시값과 명시적 연결 code 또는 선택 상태, 검색 표면 상태, 다른 입력값과 제한된 DOM mutation 및 500ms 유지로 확인한다. 예상 밖 변경은 후속 입력 중단으로 처리하며 광역 rollback하지 않는다.
4. 현재 네이버/CJ 조사는 새 구조 해석의 실사이트 성공 증거가 아니다. 두 공급자의 자동 계약 테스트와 실제 provider 호출/설치 확장 검증을 구분하며, Jev 정책 확인 플래그가 꺼져 있는 동안 실호출을 수행하지 않는다.

## 검증 경계

- 이 문서의 근거는 합성 fixture 기반 자동 테스트와 계약 테스트다. 실제 지원서 수동 검증은 사용자가 수행하며 이 문서는 실사이트 성공을 주장하지 않는다.
- 회사 전용 셀렉터나 분기는 추가하지 않았다. 증명할 수 없는 구조와 결과는 입력하지 않는다.
- 같은 PR에 달력 구조 판단 변경이 함께 포함되지만, 달력 관련 지식은 승인된 후보에 없으므로 이 문서에 기록하지 않는다.
