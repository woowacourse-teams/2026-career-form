# Greeting 어학 수준 선택지 불일치의 필드 단위 보류

## 적용 경계

CF-162까지의 Greeting 계약은 유지한다. 이 문서는 어학 등급과 회화 수준 버튼 선택이 실패할 때의 범위와 실패 코드만 추가한다.

## 실패 범위

`.grade`, `.conversationalProficiency` 이름의 `SELECT_BUTTON_OPTION`은 다른 입력란을 드러내지 않는 말단 선택이다. 이 선택이 실패하면 field 루트(`[data-scope="field"][data-part="root"][role="group"]`) 안 `[name]`이 정확히 하나일 때 그 루트만 실패 범위로 반환해 해당 필드만 건너뛰고 나머지 입력을 계속한다. `[name]`이 둘 이상인 공유 루트, 성별 같은 드러내는 드라이버, 그 밖의 명령은 범위를 반환하지 않으며 기존처럼 전체 중단한다. 날짜와 검색 격리 규칙은 그대로다.

## 실패 코드

메뉴를 연 뒤 프로필 값과 일치하는 선택지가 하나도 없으면 `OPTION_UNMATCHED`를 보고한다. 일치 항목이 둘 이상인 모호한 경우와 입력 중 상태 변경은 이 코드를 쓰지 않는다. 결과 사유는 "지원서 선택지에서 프로필 값과 일치하는 항목을 찾지 못해 이 항목만 건너뛰었습니다. 프로필 값을 확인해 주세요."이며 실제 프로필 값을 포함하지 않는다.

## 검증 범위

합성 DOM 회귀로 회화 수준 선택지가 불일치할 때 언어 선택은 입력되고 해당 필드만 `OPTION_UNMATCHED`로 건너뛰며 예외 없이 결과 화면에 도달함을 확인했다. 언어 선택 자체가 실패하면 기존처럼 중단한다. `.grade`는 범위 반환 단위 테스트로 고정했고 실제 설치 확장과 실사이트 확인은 사람 담당으로 남는다.
