# 어학 수준 선택지 불일치 처리 현황

CF-160의 Greeting 추가 필드와 검증 범위는 유지한다. CF-168은 Greeting 어학 등급과 회화 수준 버튼 선택의 선택지가 프로필 값과 하나도 일치하지 않을 때 해당 필드만 `OPTION_UNMATCHED`로 건너뛰고 나머지를 계속 입력한다고 추가한다. 드러내는 드라이버와 공유 루트의 실패는 기존처럼 전체 중단한다. 범용 경로에서는 변경 전 실패가 증명된 조건부 select·radio와 연결된 입력란만 보류한다.

자동 회귀는 합성 DOM 기준이다. 실제 Greeting 지원서의 OPIc 등급 불일치와 범용 페이지의 조건부 select 불일치는 설치 확장으로 사람이 확인한다.
