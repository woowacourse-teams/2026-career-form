## 승인한 지식 후보

가중 건수와 분모를 먼저 합산하고 0분모 및 미관측 전체 비율은 null로 제공한다. 관측 결과만의 보조 비율과 표본을 분리하며 AI 점수, 정확도와 재현율을 주장하지 않는다.

실제 STATIC/GREETING/GENERIC 경로와 차단 사유 및 실제 AI 호출을 분리한다. 사이트, 구조, 백엔드/확장/정책/모델/관측 버전으로 비교하고 schemaVersion 2 JSON 및 구형 확장을 유지한다.

실행의 DOM 제어 대응은 실행 내 임의 식별자를 해시로 검증하고 다중 snapshot 대응 미확인은 고유 칸 집계에서 제외한다. 값과 원문 DOM은 수집하지 않으며 보고 토큰은 background 문서에만 보관하고 서버에는 해시로 저장한다.

상세 30일, KST 일별 집계 90일과 영구 후보/사람 확인/발송 이력을 분리한다. 상세와 기여분의 원자적 교체 및 보존 기간 내 복구는 멱등이며 기존 Loki/Prometheus 보존 설정은 유지한다.

사람은 동일 화면의 입력 허용 가능한 칸 수를 확인한다. 분해형 제어는 각각, 하나의 선택 그룹은 한 칸이며 확인 이후의 동일 구조 실행에만 참고 분모를 적용한다. 버전만 바뀌면 재사용하며 범위 불일치와 100% 초과를 구분한다.

관리 화면은 기존 BE의 /quality/에서 HTTPS 공용 비밀번호, 8시간 서버 세션/CSRF/시도 제한과 24시간 담당 식별자를 사용한다. 별칭은 계정 인증이 아니며 미확인 ATS는 임의 기업 합치기 없이 수동 전용 호스트 확인 이후 재사용한다. 안전 공개 링크와 전체 대기/완료 이력을 제공한다.

평일 KST 09:20에 활성 미완료와 자발적 담당 포함 최대 5개 여력을 적용한다. 오래된 대기 최대 2개와 경로 순환, 나머지는 최근 7일/분모 20개 기반 입력 성공률/매핑률/사용량으로 선정한다. 당일 영속 batch와 전용 Discord wait=true 메시지 ID를 사용하며 429만 제한 재시도하고 불명확 전송은 UNKNOWN으로 자동 재발송하지 않는다.

별도 Grafana 6개 영역은 Infinity 4.1.1 서버 parser와 환경별 읽기 전용 토큰으로 집계만 조회한다. 최대 500개 그룹과 고정 버킷 근사 P95/표본/상한 초과를 표시하며 기존 운영 대시보드를 유지한다.

## 결정 근거

[ADR 164: 운영 품질 관측과 사람 확인 분모의 분리](adr/164-autofill-quality-observation.md)에 배경, 대안과 결정의 결과를 보존한다.

기존 운영 모니터링 정책을 대체하지 않는다. 이 문서는 자동 입력 품질 기능의 관측과 확인 요청 정책만 기록한다. 실제 운영 배포, 비밀번호 및 조회 토큰 설정과 Discord 수신 확인은 사람 담당 범위다.
