# 0건 안내 문구 레이어의 직접 쓴 값 직접입력

> Issue: [CF-495](https://github.com/woowacourse-teams/2026-career-form/issues/495)
> Collected: 2026-11-19
> Approval-Digest: d6888a107e5e6ef2ecf7c77b402fd6e1405528ac36adbf46fa1a87ea83b6825c
> Source-Revision: 3cd3d3c

[승인 후보 스냅샷](approved-candidates.md)의 후보 1을 적는다. 이름+등급 정확 일치는 Supersedes가 가리키는 CF-490 근거를, 직접입력 신호의 0건 인식과 행 저장 연쇄는 CF-488 근거를 그대로 따르고, 이 문서는 직접입력 진입 조건만 다룬다.

## 결정

- 범용 검색에서 결과 0건이 확인되면, 0건 안내 문구로 확인했는지 직접입력 신호로 확인했는지와 상관없이 레이어의 유일한 직접입력 경로로 프로필 원문을 기입하고 확인한다.
- 프로필 값을 카탈로그에서 골랐는지와도 상관없다. CF-488은 0건 안내 문구가 없는 레이어(직접입력 신호로 확인한 0건)에서만 직접 쓴 값을 허용했고, 안내 문구가 보이면 카탈로그 승인 값만 직접입력했다.

## 유지한 안전 조건

- 마지막 검색 시도(또는 페이지가 검색어 입력을 교체해 재시도할 수 없는 시도)일 때만 쓴다.
- 직접입력 버튼 정확히 1개, 버튼을 누른 뒤 새로 보이는 입력칸 정확히 1개, 확인 버튼 정확히 1개여야 한다.
- 결과가 1건 이상이면 직접입력을 쓰지 않는다. legacy(정적) 경로는 제외한다.
- 버튼을 눌러도 입력칸이 생기지 않으면 `unverified_search_form`으로 기입하지 않으며, 레이어는 열린 채 남는다.
