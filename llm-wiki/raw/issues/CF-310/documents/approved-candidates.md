# CF-310 approved candidates

1. 에이치닷 MRS2 요청 구조:
   - 저장은 `saveStepN`으로 갑니다.
   - `stepN.json`은 단계 데이터를 불러오는 요청입니다.
   - 학교·자격증 같은 조회는 `/com/code/retrieve*List`입니다.
   - 무저장 이동은 `writeResume`에 키 3개만 담아 보내는 POST입니다.
2. Greeting의 학교·전공 검색은 지원 페이지로 보내는 Next.js 서버 액션이고, 본문은 12–43바이트입니다.
3. Chrome은 새로고침 때 입력값을 복원합니다. 그래서 원복은 `#`을 뗀 주소로 새로 이동해야 합니다.
4. Playwright로 브라우저에 붙으면, 대화상자를 듣는 코드가 없을 때 모든 탭의 대화상자를 스스로 처리합니다. 일반 창은 닫고, 페이지 이탈 확인은 수락합니다.
5. 현대자동차 페이지는 `Map`과 `Set`을 재정의합니다. 그래서 페이지에 주입하는 함수에서는 이 둘을 쓰면 안 됩니다.
