# CF-510 승인 후보 스냅샷

> Issue: [CF-510](https://github.com/woowacourse-teams/2026-career-form/issues/510)
> Collected: 2026-11-22
> Approval-Digest: d858d35e531f8580fadc3c7984a1af4bb45d20c5563235a1984cedde5c43d215

worktree 체크포인트에 기록한 후보 다섯 개의 원문이다. 사람이 2026-11-19 "llm wiki 앞으로 잘 동작하는지 확인하고, 사람 승인 안받아도 되니 너가 알아서 기입해. 메모리에 박아놔"라고, 2026-11-22 "llm wiki는 질문하지말고 그냥 승인해"라고 말해 에이전트가 자동 승인했다.

1. 에이치닷 v1 3단계 화면 구조(#510): 경로 /v1/applicant/resume-form/<숫자>, 쿼리 step=3, v1 플랫폼 지문, 어학·자격/지식/기술·경험 구역 제목(h5)이 하나씩 있고 대상 블록이 하나 이상일 때 지원 화면이다. 어학 아래 공인외국어시험·외국어활용능력, 자격/지식/기술 아래 자격증·컴퓨터활용능력 블록이 있고 블록마다 자기 추가하기가 블록 안에 하위 줄을 붙인다. 블록 모양은 본문 > 감싸개 > [목록, 추가하기]이고 하위 줄은 [내용 div, 아이콘 버튼]이며 하위 줄이 0개인 블록에는 목록 감싸개가 없을 수 있다. 경험 구역(수상경력 등 5개)은 구역 이름의 버튼으로 카드를 붙인다. 처음에는 입력 칸이 없다.
2. 에이치닷 v1 3단계 공인외국어시험 제외(#510): 시험을 고르면 새 탭으로 외부 성적 확인 페이지가 열리고 등록번호·취득점수·만점기준 입력은 잠긴 채로 남는다. 성적은 사이트의 확인 절차로만 채워지므로 어댑터는 이 블록에서 아무것도 찾거나 수집하거나 누르지 않는다(에이전트 판단, 안전 쪽). 테스트는 이 블록의 클릭과 입력을 금지 동작으로 기록한다.
3. 에이치닷 v1 3단계 자격증·외국어활용능력 하위 줄(#510): 자격증 하위 줄은 이름 없는 검색 입력(placeholder 자격증명을 검색해주세요.)으로 시작하고 검색 요청은 POST …/search-filter/license다. 정확히 일치하는 줄을 고르면 창 없이 선택 표시(span[data-review-key] > div > div > p), 발급기관 글자 칸, 이름 없는 취득일 글자 칸(placeholder 취득일, YYYY.MM.DD 형식, 과거의 전체 날짜만), 등록번호 글자 칸이 나타난다. 검색 확정·등록하기·목록 안정 규칙은 2단계와 같고 2단계 검색 엔진을 동작 변경 없이 공용 모듈 v1-search.ts로 옮겨 함께 쓴다. 외국어활용능력 하위 줄은 언어 드롭다운이며 정확히 같은 선택지만 고른다. 기존 값과 다른 이름의 선택 표시는 덮어쓰지 않는다.
4. 에이치닷 v1 3단계 전송 계약과 범위(#510): 섹션 hplace-v1-extra, 칸 이름 hplace.v1.certificate.<i>.{licenseName,organization,acquireDate,registNumber}와 hplace.v1.languageSkill.<i>.language(i=0~9, 정확한 이름 50개), 추가 동작 hplace.v1.certificate.add와 hplace.v1.languageSkill.add(준비 요청의 ADD_REPEATABLE_GROUP, 프론트가 프로필 항목 수에서 이미 있는 하위 줄 수를 뺀 만큼 누름)다. 자격증명·발급기관·언어는 CONDITIONAL, 취득일·등록번호는 ALLOWED다. 경험 구역, 컴퓨터활용능력(프로필 범주 없음), 회화수준, 자격증 등급, 파일은 범위 밖이고 백엔드는 그 이름을 거절한다. MRS2 정책 문서는 바뀌지 않는다.
5. 에이치닷 v1 3단계 실화면 상태(#510): 측정한 유일한 v1 테넌트의 공고가 2026-11-22에 마감돼 구현한 3단계 흐름은 실화면에서 돌리지 않았다. 근거는 측정한 모양으로 만든 합성 fixture와 단위·workflow 테스트(26파일 522개 통과)다. 자격증 검색의 시간 흐름과 등록하기 줄 모양, 친 취득일의 유지, 행 제목 클릭으로 목록이 닫히는지, 처음 30개 이후의 언어 선택지는 실측하지 않았고 모두 안전 쪽으로 실패한다.
