# 세부 정보 없는 결과 목록의 카탈로그 학교명 단일 일치 선택

> Issue: [CF-477](https://github.com/woowacourse-teams/2026-career-form/issues/477)
> Collected: 2026-11-18
> Approval-Digest: 4382b5a1036e0cfaab6a7bb0a8f7b1cddb4318779acf61795da2638bc5e4a05f
> Source-Revision: ec4e0604

[승인 후보 스냅샷](approved-candidates.md)의 후보 1·2를 적는다. 원래 이름 검색의 기본 선택 경계는 Supersedes가 가리키는 CF-307 근거를 그대로 따르고, 이 문서는 카탈로그 학교명 판정 하나만 바꾼다.

## 결정 (후보 1, 사람 결정 2026-11-18)

- 범용 경로(`genericPopupRecovery`)에서 준비된 결과 목록의 어느 항목에도 세부 정보(선택지에 연결된 설명)가 없으면, 카탈로그 학교명(`highSchool`, `university`, `graduateSchool`)은 승인된 이름과 같은 결과가 정확히 1건일 때 이름만으로 선택한다.
- 이름이 같은 결과가 2건 이상이면 선택하지 않는다(`multiple_matching_results`). 이 경우에는 검색어와 이름이 정확히 같은 결과로 좁히는 기존 규칙도 쓰지 않는다.
- 결과 목록에 세부 정보가 있는 항목이 하나라도 있으면 기존처럼 이름과 세부 정보가 모두 같아야 선택한다.
- 범용 경로가 아닌 호출, 정적 어댑터, committed-search, hidden-code 경로의 "학교의 지역 근거가 없으면 catalog requiredDetail은 수동" 기준은 바꾸지 않는다.
- 자격증·어학 시험 카탈로그 판정, 카탈로그 데이터, `normalizedCatalogLabel`, `CATALOG_VERSION`은 바꾸지 않는다.

## 이유

- 학교 카탈로그 승인에는 `requiredDetail`이 항상 붙고, 결과 판정은 결과 항목의 세부 정보가 같아야 통과한다. 세부 정보는 선택지에 명시적으로 연결된 설명에서만 읽는다.
- 결과에 학교 이름만 보여 주는 지원서는 세부 정보를 비교할 방법이 없다. 그래서 카탈로그로 고른 학교는 검색이 정상이고 이름 같은 결과가 1건이어도 항상 `search_results_not_found`로 끝났다.
- 2026-11-18 실제 지원서 화면에서 실패 지점의 판정 입력을 값 없이 확인했다: 카탈로그 매칭 사용, `requiredDetail` 있음, 결과 1건, 이름 일치, 결과 세부 정보 없음. 결과는 검색 실행 뒤 그려졌고 판정은 그 뒤에 실패했으므로 타이밍 문제가 아니었다.
- 동명 학교 오선택 위험은 "이름 같은 결과가 정확히 1건"으로 제한한다. 검색어 칸을 여는 지역 선택은 같은 프로필 항목의 지역 값과 이름이 정확히 같은 선택지가 하나일 때만 고르는 기존 동작을 유지한다.

## 선택 유지 확인 (후보 2)

- 검색 선택 뒤 기입 계층의 카탈로그 재확인(`rememberCatalogSelection`)도 세부 정보를 다시 요구한다. 판정만 바꾸면 선택이 `RETAINED_VALUE_UNCONFIRMED`로 되돌아간다.
- 이름만으로 승인된 선택은 `catalogSelection.labelOnly` 표시를 전달하고, 재확인은 이 표시가 있을 때만 "세부 정보 없음 + 이름 일치"로 통과시킨다.
- 직접 입력 선택과 검색어 반영 선택은 이 표시를 내지 않으므로 유지 확인 동작이 그대로다.

## 검증과 한계

- 실패 우선 테스트 5건(판정 2, 실행기 2, 기입 계층 1)이 수정 전 실패하고 수정 뒤 통과했다. 세부 정보가 있는 목록, 범용 경로가 아닌 호출, 자격증 판정은 회귀 테스트로 고정했다.
- 실제 지원서 화면에서 새 빌드로 대학교 학교명이 선택되고 검색 레이어가 닫히는 것을 값 없이 확인했다. 저장·제출·동의는 하지 않았다.
- 행 구조 결과(행 안에 별도 선택 버튼이 있는 구조)의 판정은 바꾸지 않았다. 그 구조에서 세부 정보가 전혀 없는 학교 결과는 여전히 선택하지 않는다.
- 한 이름으로 여러 캠퍼스를 묶어 한 줄만 보여 주는 지원서에서는 그 한 줄을 고른다. 이것은 위 결정의 의도된 결과다.
