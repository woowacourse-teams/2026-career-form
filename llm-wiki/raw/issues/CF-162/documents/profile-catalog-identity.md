# 프로필 카탈로그 선택과 식별 연결

> Issue: CF-162
> Collected: 2026-10-07

## 결정

- 자격증명, 고교·대학·대학원 학교명, 어학 시험명 반복 행에 `identity`를 추가한다. 형식은 `selected`(카탈로그 ID, 정식명, 검색 원문, 카탈로그 버전) 또는 `manual`(원문)이다. 프로필 스키마 1과 기존 문자열 값은 유지한다.
- 이름을 수정하거나 지우면 이전 연결을 해제하고 `manual`로 전환한다. 등록번호, 발급기관, 취득일, 등급, 학위, 학과, 소재지 등 관련 필드는 자동으로 바꾸지 않는다.
- KESS(학교), HRDK·KDATA(자격) 공개 데이터 5,148건을 확장 번들에 포함한 오프라인 카탈로그로 제공한다. 출처, 이용 조건, 해시와 ID 한계는 `frontend/src/profile/catalog-data/README.md`가 정본이다.
- 목록 밖 항목(해외 학교 등)은 원문 직접 입력으로 저장하며 검증된 식별자로 취급하지 않는다.
- 기존 어학 시험 7종을 검색형 시험명 입력에 연결한다. 언어·등급·등록번호·취득일과 원문은 보존한다.

## 검증 범위

프로필 편집기 UI, JSON 내보내기·가져오기 왕복, 키보드·IME 동작을 자동 테스트와 로컬 production 화면에서 확인했다. 실제 사용자 프로필과 계정 정보는 사용하지 않았다.
