# Greeting 카탈로그 식별 검색 선택

> Issue: CF-162
> Collected: 2026-10-07

## 결정

Greeting 검색 선택은 프로필의 `selected` 식별자를 현재 카탈로그 ID·버전·정식명과 대조하고, 유일한 정식명 또는 승인 별칭만 선택한다. 모호한 별칭, 오래된 ID, 다른 종류의 식별자는 문자열 매칭이나 직접 입력으로 우회하지 않는다. `manual`·식별자 없는 값은 기존 정확 일치 계약을 따른다.

## 실화면 관측 (2026-10-07, 비식별)

| 항목 | 선택지 구조 | 판정 |
| --- | --- | --- |
| 고교 | 학교명 + `item-description`에 시도 약칭 1개 | 보이는 시도와 학교명 조합이 카탈로그에서 유일하고 선택한 항목일 때만 선택 |
| 대학·대학원 | 학교명과 사이트 코드만, 설명 없음. 캠퍼스는 별도 칸 | 설명이 없고 같은 이름의 카탈로그 항목이 모두 하나의 KESS 학교 코드를 공유할 때만 학교 단위로 선택 |
| 시험명 | `OPIc(영어)`처럼 언어로 한정된 라벨만 제공 | 같은 행의 보이는 언어 선택값으로 만든 `카탈로그 라벨(언어)`와 정확히 일치할 때만 선택. `OPI(...)`는 OPIc로 보지 않음 |
| 자격증 | `정보처리기사`, `SQL 개발자(SQLD)` 형태, 설명 없음 | 카탈로그 정식명·승인 별칭 일치 |

카탈로그 기준 고교 2,447건의 (학교명, 시도) 중복은 0건이다. 학교 코드가 둘 이상인 같은 이름은 대학 1건, 대학원 2건이며 입력 불가로 남는다. KESS detail 전체 문자열은 Greeting 화면에 나타나지 않으므로 전체 detail 일치를 요구하면 실화면에서 항상 실패한다.

## 검증 범위

관측한 DOM 구조를 재현한 통합 테스트, 전체 FE 테스트·타입·lint·빌드와 하네스 검증을 실행했다. 사용자가 설치 확장으로 현대오토에버 Greeting 지원서 재실행 입력을 확인했다. 저장·제출은 실행하지 않았다.
