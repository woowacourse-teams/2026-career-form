# 랜딩·온보딩 웹 페이지

## 독립 웹 빌드

웹 페이지는 frontend/site와 독립 Vite 진입점으로 관리하며 dev:site/build:site/preview:site를 사용한다. 웹 산출물 dist-site는 확장 프로그램 산출물·ZIP과 분리한다.

## 시뮬레이션의 데이터 경계

랜딩 시뮬레이션은 실제 패널·자동 기입 결과 UI에 가상 프로필 저장소와 로컬 분석 응답을 주입한다. 웹의 wxt/browser 접근은 차단하며 실제 프로필·분석 서버에 접근하지 않는다.

## 페이지의 역할

랜딩은 소개와 자동 시뮬레이션, 온보딩은 설치·프로필 등록·첫 실행 안내를 맡는다. 온보딩은 정보를 수집하거나 설치 여부를 감지하지 않고, 정책 페이지는 미시행 초안으로 유지한다.
