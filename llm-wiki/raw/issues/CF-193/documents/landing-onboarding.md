## 결정

프로필 등록은 국문 성·이름, 이메일, 전화번호, 성별, 생년월일을 한 질문씩 받는 기본 단계로 시작한다. 모든 기본 질문은 건너뛸 수 있다. 영문 성·이름과 국적은 기본 요약에서 선택해 보충하고, 저장한 정보에서는 접힌 선택 보충 단계로 제공한다. 최초 설치 때 온보딩 탭은 하나만 열리고, 시작 목적 선택 후 같은 탭에서 단계형 등록으로 전환한다.

학력은 학교·전공·재학 상태, 경력·프로젝트는 이름·역할 또는 근무 상태까지 짧게 등록한다. 기간·학위·주야간·상세 설명은 요약에서 선택해 보충한다. 저장된 정보가 있으면 재진입 시 요약부터 시작하고 원하는 질문만 수정한 뒤 원래 요약으로 돌아온다. 기존 항목은 명시적으로 선택해 같은 ID로 수정하며, 빈 진입·건너뛰기만으로 행을 만들거나 이력에서 삭제 값을 복원하지 않는다. 재학중·휴학의 졸업일과 재직중의 퇴사일은 묻지 않되 기존 값은 요약에서 알리고 사용자 동작으로만 지운다.

기존 테마·학교 검색 및 식별자·이메일 주소 완성·직접 날짜 입력·질문 초점·IME Enter를 보존한다. 모든 화면 이동은 최신 저장 성공 후에 이루어지며 실패 시 입력과 현재 화면을 유지한다. 요약의 주 행동은 자동 기입 사용 안내이고 import와 독립 동작한다.

## 기존 웹 경계

CF-96의 독립 웹 빌드와 가상 데이터 기반 랜딩 시뮬레이션 경계는 유지한다. 웹의 미설치 안내와 확장의 설치 후 단계형 등록을 구분한다. 정책 페이지는 기존 미시행 초안을 유지한다.
