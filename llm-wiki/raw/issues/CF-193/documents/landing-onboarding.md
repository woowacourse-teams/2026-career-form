## 결정

설치 후 자동 기입 준비를 선택하면 국문 성·이름, 이메일, 전화번호의 선택 입력 4개로 시작한다. 나머지는 기존 전체 프로필에서 나중에 작성하며, 저장 성공을 확인한 뒤 사용 안내나 전체 편집으로 이동한다. 기존 프로필·공고 관리·미설치 웹 안내를 보존하고 import 없이 독립 동작한다.

## 기존 웹 경계

CF-96의 독립 웹 빌드와 가상 데이터 기반 랜딩 시뮬레이션 경계는 유지한다. 웹의 미설치 안내와 확장의 설치 후 간단 등록을 구분한다. 정책 페이지는 기존 미시행 초안을 유지한다.
