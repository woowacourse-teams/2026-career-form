# 현대 v25 경력 날짜·종료사유·자격 등급 지원 현황

> Issue: CF-335

이 문서는 2026-10-24 CF-335에서 승인된 후보 3을 필드 현황 관점에서 수집한 기록이다. Approval-Digest는 [승인 후보 스냅샷](approved-candidates.md) 전체 UTF-8 바이트의 SHA-256이다. 바꾸지 않은 현황은 Supersedes가 가리키는 CF-177 근거와 그 앞의 근거를 따른다.

## 승인 후보

- 현대 v25 지원 범위 변경: 경력 입사·퇴사연월일 일자 보존, 종료사유 select 매핑과 자유입력 자동 기입 중단, 자격 등급 매핑.

## 현황

| 항목 | 구현 | 검증 상태 |
|---|---|---|
| 현대 경력 입사·퇴사연월일 | v25 직접 바인딩(YYYY-MM-DD 그대로), v24는 연월 조합 바인딩이라 일자 손실 | factory·seed 회귀 테스트; 실사이트 재측정은 dev 배포 뒤 예정 |
| 현대 종료사유 | v25 `retResCd` 버튼 선택지 16개 + `계약기간 만료`→`계약만료` 별칭, 자유입력 `retResEtcCont` 자동 기입 중단 | 후보 해소 테스트(`retResEtcCont`는 NO_MATCH); 실사이트 재측정 예정 |
| 현대 자격 등급 | v25 `grade` 버튼 선택지 82개 + `단일등급`→`등급없음` 별칭, 외국어 등급과 trigger id로 구분 | 후보 해소 테스트(`grade_1`은 자격, `gradeForeLang_1`은 외국어); 실사이트 재측정 예정 |
| 현대 전과/편입 | 규칙 없음(코드는 수집: 해당 없음 9, 전과 후 2, 편입 전 3, 편입 후 4) | 프로필 `해당`의 대응 선택지를 정할 수 없어 보류 |

- 선택지에 없는 종료사유·등급은 매핑하지 않고 "확인 필요"로 남긴다. 별칭은 관측된 문구와 띄어쓰기 변형만 두고 다른 동의어는 추정하지 않는다.
