worktree 체크포인트에 기록한 후보 네 개의 원문이다. 사람이 2026-11-19 "llm wiki 앞으로 잘 동작하는지 확인하고, 사람 승인 안받아도 되니 너가 알아서 기입해"라고 말해 에이전트가 자동 승인했다. 후보 4는 [ADR 500](adr/500-language-grade-options.md) 전문을 한 줄로 옮긴 것이다.

1. 어학 등급 표준값(#500, commit e4d8992): 등급표가 공식으로 고정된 10개 시험(OPIc 9, TOEIC Speaking 11, JLPT N5~N1, TOPIK 1~6급, HSK 1~9급, HSKK 초급·중급·고급, DELF A1~B2, DALF C1·C2, DELE A1~C2, Goethe-Zertifikat A1~C2)만 등급 표준값을 가진다. ID는 <시험 value>:<코드>(opic:al 등)이고 label은 짧은 코드, aliases는 전체 영문 표기다. 기존 OPIc 목록의 Advanced High(OPIc에 없음)를 빼고 Intermediate Low를 넣었다. 등급표 출처는 2026-11-21에 확인했다(OPIc·TOEIC Speaking 레벨표, HSK 한국사무국 3.0 전환, TOPIK 1~6급, CEFR).
2. 어학 등급 선택 화면(#500): 시험명을 카탈로그에서 골랐을 때(identity selected, catalogId languageTest:<id>, displayName이 시험명과 같음)만 languageTest.grade가 '등급' 선택 상자가 된다. field-definitions는 catalog.ts를 import하지 않고 식별 문자열에서 시험 ID를 얻는다(콘텐츠 스크립트에 카탈로그 JSON이 들어가지 않게). 표시 이름은 '전체 표기 (코드)'다. 기존 자유 입력 값은 코드·전체 표기와 정규화 뒤 같으면 그 등급으로 보이고 아니면 기존 값 선택지로 남는다. 자유 입력 칸과 요약 표시에서 등급 ID는 label로 보인다. 페이지 가져오기는 식별 없이 optionsFor를 부르므로 빈 목록을 고정 선택지 없음으로 본다.
3. 어학 등급의 자동 기입 값(#500): standard-profile-option의 PROFILE_OPTIONS와 LEGACY_TEXT_FIELDS에 languages.languageTest.grade를 넣어 등급 ID는 짧은 코드로, 자유 입력은 그대로 넘긴다. 코드를 넘기는 이유는 정적 어댑터(hplace·Greeting)가 약어를 전체 표기로 넓히는 규칙만 갖고 있어 사용자가 지금 적는 약어와 같은 값을 주기 위해서다. 사이트 선택지 매칭은 standardValueId의 코드·전체 표기 중 정확히 하나와 맞을 때만 고른다.

ADR 500 전문(#500): # 등급표가 있는 어학 시험의 등급 표준값 선택 ## 상태 승인됨 ## 날짜 2026-11-21 ## 관련 Issue - #500 ## 배경 CF-82 이후 어학 `등급·점수`는 모든 시험에서 자유 텍스트였다. 같은 등급을 `AL`, `Advanced Low`처럼 다르게 적을 수 있었고, 저장소의 OPIc 등급 목록은 화면에서 쓰이지 않았으며 OPIc에 없는 Advanced High를 포함하고 Intermediate Low가 빠져 있었다. 사용자는 OPIc, TOEIC Speaking처럼 등급이 실제로 나뉜 시험은 직접 입력 대신 시험 등급 중에서 고르게 하자고 요청했고, 적용 범위는 급수 시험까지, 점수는 따로 두지 않고 등급만 고르기로 정했다. ## 검토한 대안 - 모든 시험 자유 입력 유지(CF-82): 표기 차이가 남고 사용자가 요청한 선택 방식을 주지 못한다. 기각한다. - OPIc·TOEIC Speaking 두 시험만 선택: 범위는 작지만 같은 성격의 급수 시험(JLPT, TOPIK, HSK 등)이 자유 입력으로 남는다. 사용자가 급수 시험까지를 골랐다. 기각한다. - 등급 선택과 점수 입력 칸 분리: 점수를 묻는 지원서에는 유리하지만 프로필 스키마, 서버 필드 계약과 자동 기입 매핑이 함께 바뀐다. 사용자가 등급만 고르기로 했다. 후속 후보로 둔다. - 등급 표준값의 label을 전체 표기(Advanced Low)로 두기: 화면은 읽기 쉽지만 자동 기입이 쓰는 값이 전체 표기로 바뀐다. 정적 어댑터는 약어를 전체 표기로 넓히는 규칙만 있어 약어만 있는 선택지에서 결과가 달라질 수 있다. 기각한다. ## 결정 1. 등급표가 공식으로 고정된 10개 시험만 등급 표준값을 가진다: OPIc(NL·NM·NH·IL·IM1·IM2·IM3·IH·AL), TOEIC Speaking(OPIc 9단계와 AM·AH), JLPT(N5~N1), TOPIK(1~6급), HSK(1~9급, HSK 3.0 포함), HSKK(초급·중급·고급), DELF(A1~B2), DALF(C1·C2), DELE(A1~C2), Goethe-Zertifikat(A1~C2). 낮은 등급부터 둔다. 2. 등급 표준값 ID는 `<시험 value>:<코드>`(예: `opic:al`, `topik:3`, `hskk:beginner`)이고 한 번 정하면 바꾸지 않는다. label은 짧은 코드(AL, N1, 3급, 초급, B2)이고, 전체 영문 표기가 있으면 aliases에 둔다. 3. 시험명을 카탈로그에서 골랐을 때(식별 selected, `languageTest:<id>`, 표시 이름과 시험명 일치)만 등급 칸이 `등급` 선택 상자가 된다. 표시는 `전체 표기 (코드)` 또는 코드다. 점수형 시험과 직접 입력한 시험명은 `등급·점수` 자유 입력으로 남는다. 4. 저장 데이터는 일괄 변경하지 않는다. 등급 코드·전체 표기와 정확히 같은 기존 자유 입력 값은 그 등급으로 보이고, 그 밖의 값은 기존 값 선택지로 남는다. 자유 입력 칸에 등급 ID가 남으면 label로 보인다. 5. 자동 기입 값 연결은 등급 ID를 짧은 코드로 넘기고 standardValueId를 함께 넘긴다. 사이트 선택지 매칭은 그 ID의 코드와 전체 표기 중 정확히 하나와 맞을 때만 고른다. 자유 입력 값은 그대로 넘긴다. ## 결과 - OPIc 목록의 잘못된 Advanced High가 사라지고 Intermediate Low가 생긴다. - 사용자가 새로 고른 등급은 표준값 ID로 저장된다. 정적 어댑터는 지금 사용자가 주로 적는 약어와 같은 코드를 받으므로 결과가 바뀌지 않는다. - 점수를 묻는 지원서에서 등급표 시험은 점수를 넘길 수 없다. 이미 적은 점수 값은 남는다. 점수 칸 분리는 후속 후보다. - HSK 3.0 회화(HSKK) 체계가 바뀌면 등급표를 다시 확인해야 한다. TSC, SJPT, TEPS Speaking은 등급표 확인이 남아 자유 입력이다. - 프로필 가져오기는 식별 정보 없이 선택지를 계산하므로 빈 선택지 목록을 '고정 선택지 없음'으로 본다.
