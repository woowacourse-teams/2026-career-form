# CF-336 approved candidates (2026-10-25, 현대 학교명 검색 미확정)

1. 현대 작성 화면의 바깥 클릭 핸들러는 보이는 검색 결과 창 전부를 한 집합으로 잡고 첫 창의 hidden 값만 보고 집합 전체 표시값을 지운다. 창이 접히는 애니메이션 동안도 "보이는" 상태라, 확장은 선택 없는 검색의 창을 닫고 선택 뒤 창이 사라질 때까지 기다려야 한다(CF-336 수정).
2. 결과 패널은 검색형 칸을 실행 뒤 DOM 값 기준으로 판정해 "확인 필요"에 올린다. "입력 결과를 확인하지 못했어요"는 확장이 기입을 확인한 뒤 값이 사라진 경우다. CF-333 근거의 "입력 완료로 셌다"는 관측을 정정한다.
3. 카탈로그 신원이 없는 프로필(하네스 합성 프로필 포함)의 학교 검색은 이름만 비교해 같은 이름의 학교가 여러 지역에 있으면 "여러 개"로 남긴다. 신원이 있으면 지역까지 비교해 하나로 좁힌다. 합성 프로필로 측정할 때 고교 학교명은 이 이유로 확인 필요가 정상이다.
4. 테스트 계정 `reset`은 버튼형 위젯(학력선택·졸업여부·주야간·고용형태)을 비우지 못한다. 그 잔여가 있으면 현대 학력 준비가 "학력 종류와 입력 행을 안전하게 준비하지 못했습니다"로 멈추므로, 재측정 전에 사람이 사이트에서 해당 행을 지워야 한다. 하네스의 저장값 점검은 `widgetsLeft`로 이 수를 보고한다.
