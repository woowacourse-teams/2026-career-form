# 위치 의존 정책 발췌

`AGENTS.md`, `harness/`, 저장소 스킬, GitHub 템플릿과 컴포넌트 README는 실행 위치에 의미가 있으므로 이동하지 않는다.

회사 어댑터는 개발 기준, 대상 회사 규칙, 필드 현황 순서로 확인한다. 해당 topic Wiki가 아직 없으면 규칙을 추정하지 않고 문서 계약 공백을 보고한다. 페이지 구조가 달라져 안전한 매핑을 검증할 수 없으면 범용 매처로 우회하지 않고 해당 필드를 입력 불가로 표시한다.

작업 범위는 현재 GitHub Issue 본문이 결정한다. 위치 의존 파일에서 재사용할 결정이 바뀌면 해당 Issue raw에 새 근거를 추가하고 topic Wiki의 현재 상태를 갱신한다.
