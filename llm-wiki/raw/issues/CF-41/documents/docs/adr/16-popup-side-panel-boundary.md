# 확장 프로그램 팝업과 사이드 패널의 책임 분리

## 상태

승인됨

## 날짜

2026-08-14

## 관련 Issue

- #16

## 배경

사용자는 채용 지원서 페이지를 보면서 저장된 프로필 값을 직접 복사하거나 현재
페이지를 분석해 승인한 항목만 자동 기입해야 한다. 확장 프로그램 action popup은
빠른 진입에 적합하지만 작업 공간이 좁고 포커스를 잃으면 닫힐 수 있다. 별도 확장
프로그램 탭은 넓고 지속적인 공간을 제공하지만 지원서와 작업 화면이 분리된다.

## 검토한 대안

1. 모든 작업을 action popup에서 처리한다. 진입은 빠르지만 검색, 범주 탐색, 분석
   결과 비교와 승인 흐름을 담기 어렵다.
2. action popup에서 별도 확장 프로그램 탭으로 이동한다. 넓은 공간을 확보하지만
   지원서와 프로필 정보를 나란히 보기 어렵다.
3. action popup을 진입과 준비 상태에 사용하고, 상세 작업은 브라우저 사이드
   패널에서 처리한다. 지원서 맥락을 유지하면서 지속적인 작업 공간을 제공한다.

## 결정

확장 프로그램 action popup에는 서비스 설명, 실제 값을 노출하지 않는 프로필 준비
상태, `사이드 패널 열기`, `프로필 관리`와 안전 안내를 둔다. 현재 페이지 분석,
매핑 결과 확인과 자동 기입은 수행하지 않는다.

브라우저 사이드 패널은 프로필 검색과 범주 탐색, 항목별 수동 복사, 민감정보 개별
펼침, `자동 기입`에서 시작하는 분석, 결과 검토, 명시적 승인, 기입과 결과 요약을
담당한다.

## 결과

사용자는 지원서 페이지를 유지한 채 프로필 정보를 참고하고 자동 기입 결과를
검토할 수 있다. 후속 구현은 Chrome sidePanel API와 팝업에서 사이드 패널을 여는
연결을 고려해야 한다. 사이드 패널 미지원 환경의 호환성 정책은 이번 와이어프레임
범위에서 정하지 않고 별도 구현 Issue에서 결정한다.
