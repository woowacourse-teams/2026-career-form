# Python 하네스 진입점의 확장자 명시

## 상태

승인됨

## 날짜

2026-08-13

## 관련 Issue

- #10

## 배경

`harness/scripts/`의 Python 실행 파일은 shebang과 실행 권한을 사용하지만 파일명에
`.py`가 없다. 파일 형식이 경로에 드러나지 않고 Python 파일을 확장자 없이 추가하는
관행이 이어질 수 있다. Actions, Codex hooks, Git hooks, 스킬과 문서가 이 경로를
직접 참조하므로 이름 변경은 모든 소비자를 함께 갱신해야 한다.

## 검토한 대안

### 확장자 없는 실행 명령 유지

짧은 명령 이름을 유지할 수 있지만 파일 형식과 언어별 규칙이 경로에 드러나지 않는다.

### 별도 shell wrapper와 Python 모듈 분리

사용자 명령은 유지할 수 있지만 동일 진입점마다 wrapper가 추가돼 관리 대상이 늘어난다.

### 기존 basename에 `.py` 추가

Python 파일임을 경로에서 확인할 수 있고 구현 파일과 실행 파일을 하나로 유지한다.
모든 참조를 바꿔야 하지만 저장소 계약 테스트로 누락을 검출할 수 있다.

## 결정

- 기존 Python 진입점 15개의 basename을 유지하고 `.py`를 추가한다.
- shebang과 실행 권한을 유지해 파일을 직접 실행할 수 있게 한다.
- Actions, Codex hooks, Git hooks, 내부 코드, 테스트, 스킬과 문서 참조를 함께 바꾼다.
- Python shebang을 가진 확장자 없는 파일을 저장소 계약 테스트에서 거부한다.

## 결과

Python 진입점의 언어가 파일명에 드러나고 이후 파일 생성 규칙을 자동 검증할 수 있다.
경로 변경은 호환되지 않으므로 모든 소비자와 안내 문서를 한 PR에서 전환해야 한다.
