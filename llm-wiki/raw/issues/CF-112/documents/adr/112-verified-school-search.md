# CJ 첫 대학교 학교명 검색의 승인 묶음과 부수효과 경계

## 상태

채택됨. CF-112의 첫 대학교 학교명 검색에만 적용하며 범용 POST 또는 CJ 전체 어댑터의 허용 결정은 아니다.

## 날짜

2026-09-26

## 관련 Issue와 근거

[Issue #112](https://github.com/woowacourse-teams/2026-career-form/issues/112), 구현 `31c7e78`, 격리 브라우저 검증 기록 `9d0bdce`. 이 raw는 비식별 구조와 검증 경계만 보존한다. 이전 주전공 계약은 CF-110 결정으로 유지되며 manifest의 Supersedes 이력으로 연결한다.

## 배경

CJ 학교명 팝업은 POST와 숨김 행 문맥을 사용하며, 선택 callback은 표시값과 학교 코드뿐 아니라 국가 코드와 소재지 검색 URL의 국가 문맥도 바꾼다. CF-110의 전공 계약만으로 학교의 결합 부수효과를 승인할 수 없다. 사용자는 첫 대학교 학교명과 검증된 국가 변경까지 승인했지만 기존 소재지·전공·다른 행, 임시저장·제출은 승인하지 않았다.

## 검토한 대안

1. 기존 학교 POST 거부 유지: 안전하지만 승인된 학교명 검색 목표를 충족하지 못한다.
2. 같은 출처 POST와 callback을 범용적으로 허용하거나 전공 계약을 그대로 복사: 요청 문맥, 대상 행과 국가 부수효과가 다르므로 채택하지 않는다.
3. 첫 대학교 전용 최소 요청, inert 결과 해석, 승인된 네 효과와 팝업 종료를 별도 계약으로 고정: 제한적 지원과 기존 안전 경계를 함께 유지한다. 이를 채택한다.

## 승인된 결정: 정확히 두 후보

1. CJ 첫 대학교 학교명 팝업은 school_name·num=2_0 최소 POST와 inert 결과 literal의 학교 코드·국가 코드를 검증한다. 소재지 표시·코드가 비어 있으면 첫 행 학교명·코드·reg_region·해당 행 소재지 opener URL 국가 문맥만 함께 변경한다. 기존 new_country가 선택 국가와 달라도 보존하고 거부하지 않는다. 이미 동일 학교명이 있다면 실제 응답으로 코드·국가·URL 전체를 재검증해야 unchanged로 분류한다. 원본 callback·bookmark·지원서 제출은 호출하지 않는다.
2. CJ 학교·전공 팝업은 검토된 needPopup show/hide 사양과 MAIN-world bridge의 단일 lease map으로 직렬화한다. 팝업 종료·후속 500ms 유지 및 원래 행 소유를 확인하고, 실패 시 아직 소유한 값과 URL만 조건부 복구한다. 완전 수신한 구조 검증 HTML의 유일한 정확 일치만 선택 근거이며 데이터베이스 전체 유일성은 아니다.

## 결과와 검증 한계

기존 소재지 표시값·지역 코드가 있으면 국가 정합성을 추측하지 않고 쓰기 전에 보류한다. 일반 POST·hidden·inline handler의 범용 거부와 기존 전공 검색 계약은 유지한다. 결과 callback, bookmark, 지원서 완료 표시·제출은 실행하지 않는다. 계약이 깨지면 범용 경로로 우회하지 않는다.

비식별 응답 fixture의 자동 테스트와 별도의 합성 문서 브라우저 검증을 구분한다. 공개 CJ 검색과 검토된 공개 팝업 라이브러리를 연결한 합성 대상에서 두 번 선택됐으며 팝업 종료 뒤 각각 549ms, 533ms 유지와 국가 문맥·범위 밖 필드 보존을 확인했다. 별도의 공개 기본 검색에서 정확 결과 코드와 합성 하네스 기록 코드의 독립 일치를 확인했지만 결과 링크는 누르지 않았다. 설치 확장 전체 패널, 실제 지원서 필드, 서버 저장·제출, CJ 데이터베이스 전체의 유일성은 검증하지 않았다.
