# SK·현대 실시간 옵션 선택 보완

> Source: [Issue #82](https://github.com/woowacourse-teams/2026-career-form/issues/82) 구현 범위
> Collected: 2026-09-09
> Published: 2026-09-09

## 상태

승인됨

## 결정

CF-46에서 기록한 회사별 DOM 식별·조건부 처리·반복 행 보호는 그대로 유지한다. CF-82는 표준 ID가 전달된 선택형 어학 값의 선택 규칙만 보완한다.

현대의 버튼 메뉴는 현재 열려 있고 `data-code`를 가진 옵션을 수집해 명시적 별칭으로 정확히 하나를 찾을 때만 클릭한다. 클릭 뒤 표시 라벨과 hidden code를 다시 확인한다.

SK의 jQuery 자동완성 메뉴는 현재 보이는 nonzero ID 후보 하나만 확정한다. 표준 ID는 표시 라벨 또는 언어 괄호를 제외한 라벨이 명시적 별칭과 일치할 때만 후보가 된다. 후보가 없거나 여러 개면 자동 선택하지 않는다.

## 제한

- 프로필의 어학 자유 텍스트는 표준 ID로 승격하거나 추측 매칭하지 않는다.
- 이 보완은 SK·현대 외 회사에 정적 코드나 회사별 프로필값을 추가하지 않는다.
- 실제 사용자 지원서의 저장·이동·제출과 실제 사이트의 개인 입력값은 검증·기록 범위 밖이다.
