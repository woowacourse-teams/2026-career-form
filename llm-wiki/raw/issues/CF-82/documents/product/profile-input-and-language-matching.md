# 프로필 입력과 안전한 어학 선택

> Collected: 2026-09-09
> Published: 2026-09-09

## 상태

승인됨

## 결정

어학의 외국어·시험명·등급은 회사별 표현 차이를 담을 수 있도록 자유 텍스트로 입력한다. 학교 소재지와 주·야간처럼 제한된 선택지는 표준 ID 기반 드롭다운을 유지한다. 기존 문자열 프로필과 JSON 가져오기 데이터는 그대로 읽고 내보낸다.

프로필 값이 표준 ID인 경우에만 자동 입력은 현재 지원서에서 수집한 실제 옵션과 명시적 별칭을 비교한다. 정확히 하나인 후보만 선택하고, 후보가 없거나 여러 개면 어떤 옵션도 추측해 선택하지 않는다. SK와 현대 어댑터의 선택 코드는 정적 사전이 아닌 그 순간 페이지에 표시된 옵션에서 얻는다.

프로필 화면의 표시 그룹, 검색, 입력 건수는 저장 필드 정의와 분리된 표현 계층이다. 새 필드는 미분류로 누락 없이 표시하며, 등록 건수는 프로필 완성도를 뜻하지 않는다. 전화번호는 입력 단계에서 숫자만 남기고 11자리까지만 보존한다. 하이픈이 든 붙여넣기도 정규화 전 native maxlength로 잘리지 않는다.

## 사용자 보호 경계

- 회사 화면의 실제 옵션이 유일하지 않으면 자동 선택하지 않는다.
- 실제 프로필값, 지원서값, 계정·세션·원본 DOM은 이 문서에 기록하지 않는다.
- 기존 프로필과 JSON은 강제 변환하거나 삭제하지 않는다.
- 실제 지원서 저장·이동·미리보기·제출은 이 변경의 실행 대상이 아니다.

## 제외 범위

모든 프로필 범주의 표준화, 유사도 또는 AI 기반 값 추측, 회사 옵션의 서버 동기화, 실제 사용자 프로필 일괄 변환은 포함하지 않는다.
