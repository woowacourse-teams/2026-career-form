승인됨

## 결정

프로필 관리는 의미별 그룹, 필드명 검색, 실제 등록 수, 반복 항목 요약과 인접 범주 이동으로 탐색한다. 긴 입력과 주소는 넓게 표시하고, 새 반복 항목의 첫 입력에 초점을 맞춘다.

확장 프로그램의 popup, 사이드 패널과 주입된 지원서 패널은 하늘색을 화면 바탕으로 사용하고 카라멜은 주요 동작·강조에만 사용한다. 코코아 계열은 제목과 계층을 구분하는 텍스트 색으로 제한한다. Shadow DOM 패널은 공유 UI 폰트를 명시하고, 마스코트 이미지는 채용 사이트가 아닌 확장 리소스 URL에서 불러온다.

## 사용자 보호 경계

- 패널은 프로필 탐색, 수동 복사와 자동 기입 검토 진입을 제공할 뿐 저장·이동·제출을 실행하지 않는다.
- 패널에 실제 프로필값을 지식 문서나 진단 기록으로 남기지 않는다.
- 색상과 레이아웃 변경은 저장 구조·자동 기입 승인·쓰기 로직을 바꾸지 않는다.
