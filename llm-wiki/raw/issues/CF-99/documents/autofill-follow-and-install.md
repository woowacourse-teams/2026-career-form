# 입력 결과 검토와 설치 안내

## 승인된 결정

1. 자동 기입은 기존 in-page 실행 경로와 승인 경계를 유지하며 입력 중 화면을 자동으로 따라 이동시키지 않는다. 결과에서 사용자가 항목이나 범주를 선택할 때 위치를 안내하고 강조한다. 다음 대상과 실행 종료 시 소유한 스타일 및 임시 패널 위치를 복구하며, 사라지거나 가려진 대상의 위치 이동을 성공으로 표시하지 않는다.

2. 결과는 입력 완료, 확인 필요, 입력 실패를 구분한다. 승인되지 않았거나 불확실한 항목은 간단한 확인 필요 행에 남기며 저장된 값과 실제 수집된 선택지, 사유, 동일 페이지 필드 이동을 제공한다. 표시를 위해 자동 선택이나 기존 입력 정책을 바꾸지 않으며 민감값 보호를 유지한다. 결과의 부가 안내와 가운데점 구분자는 제거한다.

3. 첫 install 이벤트에서만 확장 내부 onboarding.html을 새 탭으로 연다. 기존 안내 컴포넌트를 재사용하고 실제 프로필 관리 화면으로 연결한다. 배포 URL은 추측하지 않으며 update와 브라우저 재시작에서는 안내를 자동으로 열거나 기존 프로필을 초기화하지 않는다.

4. 입력 완료 검토는 연락처와 주소, 직장경력, 어학 등 범주 단위로 이동한다. 실제 입력·조작한 텍스트 입력칸과 선택 컨트롤만 같은 강조색으로 표시하며 라벨 글자를 피하고 다른 범주 선택 시 이전 강조를 해제한다. 확인했어요는 선택적인 세션 내 접기이며 저장·제출·필수 검증을 의미하지 않는다. 패널 내 직접 수정은 제공하지 않는다.

5. 랜딩은 반복 입력 절감의 가치와 자동 입력 시연을 중심으로, 온보딩은 설치·프로필 등록·패널 실행·남은 값 복사와 붙여넣기 순서로 안내한다. 결과 시연은 실제 확인 필요 행을 재사용한 합성 화면이며 실제 프로필과 시스템 클립보드에 접근하지 않는다. 프로필·수정·패널·안내 화면은 밝은 바탕과 절제된 갈색 강조를 공유한다.

6. 현대·SK 검색 실패는 값이 없는 허용된 진단 코드로 결과 패널에 전달한다. 검색 결과 없음·정확 일치 없음·복수 후보·시간 초과·선택 미확인·시험 성적란 준비 실패를 구분하되 유일한 정확 결과 확인과 기존 지원 범위는 유지한다. 최신 범용 입력의 승인 재검증·중단·날짜 변환 경계는 진행 표시를 연결해도 유지한다.

## 적용 경계

입력 실패 사유는 확인 필요 목록 안에서 구분하며 별도 실패 탭을 만들지 않는다. 기존 입력 판단, 데이터 스키마와 회사별 지원 범위를 바꾸는 결정이 아니다. 실제 확장 설치/업데이트와 최종 화면 수동 확인은 자동 테스트와 별도로 수행한다.
