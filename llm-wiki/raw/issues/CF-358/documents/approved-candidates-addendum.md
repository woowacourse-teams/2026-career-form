# CF-358 승인 후보 (추가 승인)

사람이 2026-10-29 저녁에 "1. 새 칸 2차 버튼 제거, 2. 확인 필요 자동 포함 규칙, 3. 승인 범위 확장, 4. 날짜 뒤 보류 판정 예외"로 승인한 후보 4개다.

1. 제품 결정: 실행 중이나 저장 뒤 새 칸이 나타나도 2차 검토 버튼을 띄우지 않는다. 승인 범위 안의 빈 칸은 바로 기입하고, 나머지 새 칸은 결과 화면의 "직접 확인할 새 칸"에 표시한다.
2. 제품 결정: 확인 필요에는 기존 값이 있는 칸, 연결 확신 보통(MODERATE_CONFIDENCE), 같은 선택지 없음(OPTION_VALUE_UNMATCHED), 실행 중 검색 결과 여러 개만 남긴다. 나머지 확인 필요 등급과 조건 확인(CONDITIONAL) 칸은 처음부터 포함해 자동 기입 예정으로 보낸다.
3. 제품 결정: 승인 범위는 1차 검토에서 쓸 수 있게 보인 칸이 덮지 않은 모든 범주의 저장 값이다. 1차 검토에서 숨은 칸, 입력 불가였던 조건부 칸, 영역 자체가 없던 범주를 포함한다.
4. 기술 지식: 날짜 기입 뒤 보류 판정에서 새로 보인 층의 열기 컨트롤(aria-controls)이 대상이 아닌 다른 컨트롤이면 그 층은 이번 기입의 변화로 세지 않는다(다른 칸 검색 제안 목록이 늦게 보인 사례).
