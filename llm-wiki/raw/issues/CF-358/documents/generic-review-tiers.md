# 미리 승인한 새 칸의 2차 검토 없는 기입

## 승인한 지식

- 제품 결정(2026-10-29): 범용 경로의 1차 검토는 "나타날 수 있는 칸"을 보여 준다. 대상은 검토에 나온 범주의 저장된 프로필 값 중 아직 보이는 칸이 없는 것(프로필 키와 항목 순번)이다(`frontend/src/autofill/workflow/pre-approval.ts`의 `appearableProfileItems`).
- 사용자가 체크를 켜 둔 채 실행하면, 실행 중 새로 나타난 칸과 사용자가 페이지의 저장 버튼을 직접 누른 뒤 나타난 칸 중 승인 범위 안의 빈 AUTO 칸을 2차 버튼 없이 기입한다(`isPreApprovedItem`). 범위 밖, 확인 필요 등급, 기존 값이 있는 칸은 지금처럼 2차 검토로 보낸다. 사용자는 체크를 끌 수 있다.
- 저장 뒤 감시(`frontend/src/autofill/workflow/reveal-watch.ts`)는 아무것도 누르지 않는다. 사용자가 입력 중이거나 새 칸에 포커스가 있으면 기다리고, 페이지 주소가 바뀌면 멈춘다. 워크플로는 프로필 변경, 승인 항목 모두 처리, 감시 5회에서 감시를 끝낸다. 결과 화면에 "다시 묻지 않고 기입한 새 칸"을 표시한다.

## 근거와 경계

이 결정은 승인 범위 해석을 "보이는 칸"에서 "1차 검토에서 보여 준 프로필 값과 칸 종류"로 넓힌다. 회귀 테스트는 `pre-approval.test.ts`, `reveal-watch.test.ts`, `AutofillWorkflow.pre-approval.test.tsx`(범위 밖 자동 기입 없음, 체크 해제 시 2차 검토, 확장의 저장 클릭 0건)에 있다. 정적 어댑터 경로의 드러난 칸 기입은 바꾸지 않는다. 실제 지원값, 계정, 세션은 옮기지 않는다.
