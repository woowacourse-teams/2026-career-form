# 자동 기입 검토 표면: 웹페이지 모달

> Source: Issue #47 확정 범위와 기존 ADR #16
> Collected: 2026-08-26
> Published: 2026-08-26

## 상태

승인됨

## 관련 Issue

- #47

## 배경

자동 기입은 현재 지원서 필드, 기존 값, 예정 값, 입력 가능 여부와 사유를 한 화면에서 비교하고 사용자의 단계별 승인을 받아야 한다. 사이드 패널은 프로필 탐색과 수동 복사에는 적합하지만, 페이지의 실제 필드와 비교하는 검토 표면으로는 폭과 맥락이 제한된다.

## 결정

사이드 패널은 프로필 검색·수동 복사와 웹페이지 자동 기입 모달을 여는 명시적 시작점으로 유지한다. 자동 기입의 Snapshot A/B 분석, 준비 동작 승인, 필드 검토, 민감정보 개별 펼침, 기존 값 덮어쓰기 승인, 최종 승인과 결과는 지원서 페이지의 Shadow DOM 모달에서 진행한다.

모달은 승인 전 지원서 값을 변경하지 않고, 저장·이동·미리보기·제출을 실행하지 않는다. 프로필 값과 현재 control 값은 브라우저에만 두며 분석 API에는 비식별 구조만 보낸다.

## 대안

1. 사이드 패널에서 전체 자동 기입 검토를 수행한다. 프로필 탐색은 편하지만 페이지 필드·현재 값·예정 값을 함께 비교하기 어렵다.
2. 별도 확장 프로그램 탭에서 수행한다. 공간은 넓지만 지원서 맥락과 분리된다.
3. 웹페이지 Shadow DOM 모달에서 수행한다. 지원서 맥락을 유지하면서 승인 대상과 상태를 함께 비교할 수 있다.

## 결과

ADR #16의 팝업·사이드 패널 책임 중 자동 기입의 분석·검토·승인·결과 표면만 이 ADR로 대체한다. 팝업의 빠른 진입과 사이드 패널의 프로필 탐색·수동 복사 책임은 변경하지 않는다.
