| 수치 | 측정 조건 |

| 지원서 평균 입력 정보 48개 | 실제 대기업 채용 사이트 지원서 5페이지 평균 |

## 비식별 확인

- 화면 속 이름, 연락처, 이메일, 주소는 `예시`, `사용자`, `010-0000-0000`,
  `example@example.test`, `윤티모`, `010-1234-567` 같은 예시 값이다.
- 회사와 공고 목록은 `커리어 테크`, `모래 랩스` 같은 가상 이름이다. 실제 채용 페이지
  화면을 쓴 17쪽은 회사 식별 정보가 가려져 있다.
- 팀 표기는 활동 닉네임(티모, 모아, 레서, 영기)만 있다.
- 실제 지원서 입력값, 계정, 세션 정보는 없다.
