# 범용 자격증 검색과 후속 재검토 경계

근거: [Issue #114](https://github.com/woowacourse-teams/2026-career-form/issues/114), 구현 `38c15414e3005ee49ed5bdf1f7cd042aeef3033e`.
기존 CF-112 학교 검색 계약과 그 선행 계약은 유지한다. 이전 근거는 manifest의 Supersedes로 연결한다. 이번 문서는 회사 중립 자격증 흐름과 검증 경계를 추가하며 CJ 전용 어댑터 신설이나 기존 계약의 전면 교체가 아니다.

## 승인된 후보 전체

1. 범용 반복 행은 명시적 반복 표식, 다중 필드 구조, 영역 의미, 유일한 추가 동작을 함께 확인하고 현재 영역의 명시적 최대값과 매 클릭의 정확한 1행 증가 및 기존 값 불변을 검증한다.
2. 범용 검색은 현재 form과 query 및 결과 세대를 연결하고 완결된 후보 집합의 유일 정확 일치만 선택한다. 선택 전 같은 행의 변경 범위와 관계 값을 바인딩할 수 없으면 클릭하지 않는다.
3. 검색형은 같은 프로필 항목의 명시적 이름과 등급으로 로컬에서 원본 및 왕복 가능한 분리형 최대 2개만 만든다. 원본 검색의 완결된 결과 없음 이후에만 분리형을 시도하며 값과 검색어를 API에 추가 전송하지 않는다.
4. 검색 후 같은 행에 나타나거나 활성화되거나 옵션이 바뀐 필드는 재수집 및 재분석하고 새 승인을 요구한다. 완료한 검색은 재실행하지 않으며 이후 이름, 행, 프로필이 달라지면 후속 쓰기를 차단한다.
5. 합성 회귀 성공과 실제 사이트 지원을 구분한다. 관찰한 CJ 결과는 완료 근거와 명시적 선택 코드 관계가 부족하므로 실제 자동 기입 성공으로 주장하지 않는다. CJ 적응을 위해 범용 안전 조건을 완화하지 않고 다른 회사에 적용 가능한 공통 경로 개선을 우선하며 개별 회사 지원 확대는 별도 검증 범위로 둔다.

## 구현과 지원 범위

현재 DOM의 native GET/POST form, query, hidden routing과 응답 세대를 검증한다. 기존의 일괄 POST/hidden 거부에서 이 검증된 native form 범위만 확장한다. inline handler나 불투명 callback을 범용적으로 허용하는 변경은 아니다. 회사별 이름 사전, 고정 URL/ID 분기, callback 직접 호출, readonly 해제나 hidden 직접 쓰기는 추가하지 않는다.

후속 필드는 기존 분석 API와 writer를 재사용한다. 날짜는 의미와 행 연결이 확인된 경우에만 기존 변환을 사용하며 이름 선택만으로 등급까지 완료했다고 집계하지 않는다.

## 검증 경계

- 세 가지 합성 마크업에서 각 3개 자격증의 준비·검색·후속 재검토·입력을 자동 테스트했다. 합성 완료 표식은 실제 사이트의 근거가 아니다.
- 설치 확장의 빌드 일치는 확인했으나 설치 확장 전체 자동 기입 smoke는 미완료다.
- 실제 CJ에서는 검색 구조를 관찰했으며 자동 결과 선택과 지원서 전체 입력 성공은 입증하지 않았다. 저장·제출은 실행하지 않았다.
- 다른 회사의 실제 지원 확대도 이 자동 테스트만으로 주장하지 않는다.
