# Greeting v19 직접 입력 지원 범위와 카카오게임즈 기존 미해결 항목

> Issue: CF-346
> Collected: 2026-10-25
> Approval-Digest: fe9263182f4be99fa243d40d23b9a65061d4226063cc78707b5149c59599feb3
> Source-Revision: d5a5005cc47d628b9044e460e0956021df523c90

이 문서는 2026-10-25 CF-346에서 승인된 후보 1의 v19 지원 범위와 후보 5를 필드 현황 관점에서 수집한 기록이다. Approval-Digest는 [승인 후보 스냅샷](approved-candidates.md) 전체 UTF-8 바이트의 SHA-256이다. 바꾸지 않은 현황은 Supersedes가 가리키는 CF-335 근거와 그 앞의 근거를 따른다. 값은 합성 프로필이고 실제 지원값·계정·세션은 포함하지 않는다.

## 승인 후보

- Greeting v19 지원 범위 변경: 대학·대학원 학교명과 전공명 검색에서 정확한 정식 항목이 없고 사이트가 `직접 입력하기:“<값>”` 선택지를 하나 제공하면 그 선택지로 프로필 값을 기입한다. 시험명·국적은 사이트가 직접 입력을 주지 않아 허용하지 않고 사유 코드만 보고한다.
- 카카오게임즈 Greeting 양식의 기존 미해결 항목 8칸은 검색 정확 일치와 무관하며 CF-346 범위 밖이다.

## 현황

| 항목 | 구현 | 검증 상태 |
|---|---|---|
| Greeting 대학·대학원 학교명 직접 입력 | v19 `patterns.directSearch`에 대학(`universities.<n>.schoolName`)·대학원(`graduateSchools.<n>.schoolName`) 학교명 추가. 정확 항목 없음 + 유일한 직접 입력 선택지일 때만. 카탈로그 신원(KESS 코드) 확정 학교는 제외 | 회귀 테스트; 컬리 공개 공고 합성값 읽기 전용 관측 1회(직접 입력 선택지 제공 확인) |
| Greeting 전공명 직접 입력 | v19 `….majors.<n>` 추가. 같은 조건 | 회귀 테스트; 컬리 로컬 스택 v19 5회 모두 완료 74·확인 필요 0(수정 전 50회 71·3), 전공명 세 칸 직접 입력으로 채워짐 |
| Greeting 고교 학교명·회사명·자격증명 직접 입력 | v18과 같음(기존 허용 종류) | 카카오게임즈·컬리 합성값 관측에서 직접 입력 선택 성공 |
| Greeting 시험명 | 직접 입력 허용 안 함. 닫힌 목록에 정확 항목 없으면 `SEARCH_NO_EXACT_MATCH` | 카카오게임즈 합성값 관측 1회 |
| Greeting 국적 | 직접 입력 허용 안 함. 전체 목록이 클라이언트 필터로 비면 `SEARCH_NO_RESULTS` | 카카오게임즈 합성값 관측 1회 |
| Greeting 검색 실패 사유 | `SEARCH_NO_EXACT_MATCH`·`SEARCH_AMBIGUOUS`·`SEARCH_NO_RESULTS`·`SEARCH_TIMEOUT` 구분 보고, 기본 코드 `SEARCH_UNCONFIRMED`는 팝업 미개방만 | 회귀 테스트 11개 |

- 컬리 지원서 누락 전수 점검(develop 빌드 10회 + 수정 빌드 40회): 결정적으로 비는 칸은 전공명 세 칸뿐이었다. 그 밖에 비어 끝나는 칸은 재직 중 체크박스(프로필이 퇴사라 미체크가 정답), 지원 경로(사이트 질문, 프로필 키 없음), 파일 2·동의 4(기입 금지), 첫 전공 행의 전공 구분(사이트 기본값 `주전공`)으로 모두 의도된 결과다.
- 카카오게임즈 기존 미해결 항목(2026-10-24·10-25 동일): 어학 2·자격 3의 취득일 "선택값이 유지되지 않았어요", 어학 등급/점수 선택지 불일치 1, 회화수준 2. 동명 고교(세 지역)는 합성 프로필 한계로 v19 뒤 "여러 개"로 표시된다. 상세는 [Greeting 어댑터 근거](greeting-direct-input-and-search-failure-codes.md)를 따른다.
- 다른 플랫폼(현대·SK·Hplace)의 검색 칸에서 정확 일치가 없을 때의 처리는 검색 위젯과 정책이 달라 v19로 다루지 않는다. 같은 전수 조사 방식으로 플랫폼별 현황을 먼저 관찰한 뒤 별도 후보로 올린다.
