# 어댑터 구현·검증 현황

이 표는 CF-46에서 분리한 프론트 기능의 현황이다. 회사의 모든 필드가 지원된다는 목록이나 실제 사이트의 최신 동작 보장이 아니다. 개별 필드 연결은 활성 백엔드 정책과 현재 DOM의 검증 결과를 따른다. 확인하지 않은 필드는 추정하지 않는다.
