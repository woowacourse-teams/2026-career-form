# SK 프론트 어댑터

## 구현 경계

`frontend/src/autofill/adapters/sk/collection.ts`는 필드 수집에서 숨김 템플릿 행을 제외하는 회사 규칙을 소유한다. 준비 단계와 일반 사이트에 같은 예외를 확대하지 않는다.

`frontend/src/autofill/adapters/sk/workflow.ts`는 학력 DOM 별칭, 신규 학력 행 기본값, 어학 선행 선택, 복수·부전공 선택과 후속 바인딩 판별을 소유한다. 교육 분류의 대학원·고등학교·대학 우선순위를 유지한다. 공통 워크플로가 로컬 프로필 값 해석, 분석 요청, 재수집과 최종 입력을 조정한다.

서버가 반환한 정확한 후속 프로필 바인딩과 text 입력 명령에 더해 `interactionStatus: READY`인 필드만 후속 입력한다. 여러 프로필 항목 중 하나를 유일하게 결정할 수 없으면 입력하지 않는다. 진단에는 값 대신 코드와 개수만 남긴다.

## 확인된 자동 검증 범위

- 숨김 템플릿 제외와 일반 사이트 행 개수 보존.
- 어학 선행 선택 성공 후 재수집·재분석, 실패 시 잘못된 후속 실행 방지.
- 신규 대학 행 기본값의 회사 한정 처리.
- 정확한 후속 바인딩, READY 상태와 단일 프로필 항목 검증.
- 차단된 분석과 비 READY 필드의 미입력.
- 실제 프로필 값이 진단 로그에 포함되지 않는지 비식별 값으로 검증.

이 기록은 비식별 자동 테스트와 코드 조사에 근거한다. 실제 채용 페이지를 이번 작업에서 조작하거나 수동 검증하지 않았다.

## 제한

기존 자동 승인 및 문서 전체 첫 일치 라디오 선택 방식은 유지한다. 이번 분리를 반복 행별 검색·선택 안전성이 완성된 것으로 해석하지 않는다.
