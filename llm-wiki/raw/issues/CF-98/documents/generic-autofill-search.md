# CF-98 범용 검색 표면과 실측 경계

> 근거: [Issue #98](https://github.com/woowacourse-teams/2026-career-form/issues/98), CF-98 구현 및 비식별 브라우저 관측.

## 검색 실행 계약

승인되고 프로필 값이 있는 readonly DIRECT 필드에서만 SEARCH_SELECTION을 고려한다. 검색 opener, query, submit과 결과를 분리해 소유 관계, 유일 후보, 현재 대상과 표면 상태를 조작 직전 재확인한다. 결과는 모델 생성 callback이나 selector가 아니라 로컬 exact matcher로만 고른다. 검색어가 없는 국내 학교 소재지 목록은 한국 국가 문맥, 동일 출처 iframe, 완전한 국내 17개 지역 목록과 명시적 지역 별칭을 확인한 경우만 대상으로 한다.

사이트가 `javascript:` 결과 링크를 사용하면 회사 함수를 직접 호출하거나 주소 문자열을 평가하지 않는다. 링크가 표시 라벨과 일치하는 단일 함수 호출·리터럴 인자, 다른 handler·form·외부 target이 없는 원본 링크인지 검증하고, 현재 소유 iframe의 MAIN-world에서 그 링크만 한 번 클릭한다. 클릭 뒤 대상 표시값의 반영, 표면 종료 및 유지 시간을 확인한다. 링크 변경, 중복, 예상 밖 탐색, 무응답 또는 반영 실패는 성공으로 기록하지 않고 재클릭·다른 필드 후속 쓰기 없이 중단한다. readonly 해제와 hidden code 직접 쓰기도 하지 않는다.

반복 행, 조건부 필드와 native/custom 선택은 후보와 현재 행의 유일성, DOM 재수집, 기존 값 충돌 및 실제 제어 상태를 확인한다. 모델 분류와 로컬 실행 검증 중 하나라도 불확실하면 자동 입력하지 않는다.

## 관측된 범위

비식별 localhost 합성 검색 양식에서는 실제 설치 확장의 UI 경로로 두 학교 소재지 표시값 반영과 팝업 종료를 확인했다. 같은 양식의 재실행에서 표시값은 유지됐지만 패널 항목은 승인 없이 건너뜀으로 집계돼 완전한 UI 성공으로 기록하지 않는다.

실제 CJ 작성 화면의 이전 실행에서는 검색 결과 활성화 또는 팝업 탐색이 위험으로 판정되어 후속 입력을 멈춘 적이 있다. 이후 사용자의 확인을 받아 같은 열린 탭을 다시 읽었을 때 고교·대학 소재지 표시칸은 모두 채워져 있었고 해당 검색 iframe은 없었다. 이 최신 화면 관측만으로 중간 실행의 항목별 확장 성공 판정, hidden code, 서버 저장 상태와 재실행 안정성을 독립 검증한 것은 아니다. 실제 지원서 저장·제출·다음 단계·미리보기는 AI가 실행하지 않았다.

Jev 실제 외부 호출과 보관 정책, Greeting 실제 작성 화면, 실제 CJ의 고급 검색 제어 전체, 모든 사이트 호환성은 미검증이다. 자동 테스트·합성 성공을 이 범위의 성공으로 치환하지 않는다. 프로필 값, 계정, 세션 URL, 화면 원문은 이 기록에 남기지 않는다.
