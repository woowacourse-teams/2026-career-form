# 현대 작성 화면의 재진입 불가와 경력 칸 결함 관측

> Issue: CF-333
> Collected: 2026-10-24
> Approval-Digest: e3220900fa34d5fd1ee3718f11713ef2c78fa8bbdb93741c0fa6e1be570f8e41
> Source-Revision: fe786252f656a3e551a55bfa1825032e2366a086

이 문서는 2026-10-24 테스트 전용 모드 전환에서 승인된 CF-333 후보 1·4·5를 수집한 기록이다. Approval-Digest는 [승인 후보 스냅샷](approved-candidates.md) 전체 UTF-8 바이트의 SHA-256이다. 어댑터 계약을 바꾸지 않는 관측이며, 수정은 별도 Issue #335로 다룬다. 바꾸지 않은 내용은 Supersedes가 가리키는 CF-310 버튼형 선택지 코드 근거를 따른다. 실제 지원값·계정·세션·URL 쿼리·대화 전문은 포함하지 않는다.

## 승인 후보

- 현대자동차 작성 화면(`applyWrite.hc`)은 같은 주소로 다시 접속하면 본문이 비어 하네스가 재진입할 수 없고, 사람이 사이트의 지원서 목록에서 다시 들어가야 한다.
- 경력 행의 입사·퇴사연월일 칸에 연월만 기입돼 일자가 빠진다.
- 종료사유는 select를 비운 채 "기타"일 때만 유효한 자유입력 칸에 원문이 기입된다.

## 근거

### 재진입 불가

- 2026-10-22 확장 재설치 뒤 콘텐츠 스크립트 복구를 위해 열린 탭을 같은 주소로 다시 열었을 때, 에이치닷·SK·Greeting은 복구됐지만 현대자동차 `applyWrite.hc`는 본문이 빈 화면으로 열렸다. 지원서 목록에서 사람이 다시 들어가야만 작성 화면이 나온다. CF-333의 `start` 복구는 이 호스트의 작성 화면을 `needsPerson`으로 분류해 자동 재접속을 시도하지 않는다.

### 입사·퇴사연월일 일자 누락

- 2026-10-21·22 두 차례 측정의 현대자동차 3곳, 경력 2행 모두에서 `tranStartDt`·`tranEndDt`(`maxLength 10`, YYYY-MM-DD 형식 칸)에 연월만 들어갔다. 같은 페이지의 자격 취득연월일은 YYYY-MM-DD로 온전히 들어가므로 형식 변환이 아니라 값 손실이다. 프로필의 경력 기간은 연월 단위라 일자를 어떻게 채울지는 정책 결정이 필요하다.

### 종료사유 자유입력 오배치

- 같은 3곳에서 종료사유 select(`retResCd`)는 선택되지 않은 채, "기타" 선택 시에만 유효한 자유입력 칸(`retResEtcCont`)에 프로필의 사유 문구가 들어갔다. 사용자가 select를 고르고 자유입력을 지워야 한다. 프로필 어휘("계약기간 만료")와 선택지("계약만료")의 별칭 매핑이 필요하고, 버튼형 선택지의 코드는 레이어를 열어야 보이므로 코드 수집이 선행돼야 한다. 판정 규칙은 이 경우 select를 누락으로, 자유입력 쓰기는 세지 않고 "substitute write"로 적는다.

## 쓰임

- 현대자동차 탭은 재설치·교체 뒤 사람이 목록에서 다시 들어간다. 하네스 보고의 `needsPerson`이 그 목록이다.
- 두 결함의 수정과 자격 등급 `단일등급` 매핑은 #335에서 다루고, 학교명 검색 미확정은 #336에서 재현 기록부터 모은다.
