# 실행 단위 품질 배치 보고

## 전송 시점과 내용

완료 또는 취소 후 입력값 유지 관측이 정리되면 여러 스냅샷의 필드 상태, 대응 식별자, eventId, snapshotId를 reports 배열로 묶는다. 전체 UTF8 JSON 본문이 128KiB 이하면 보고 한 번으로 보내고, 넘으면 실제 본문 크기로 나눈다. 마지막 항목에 종료 상태를 둔다. 사용자 완료는 보고 전송을 기다리지 않는다.

기존 단건 /report도 같은 경로에서 지원한다. HTTP 요청을 묶는 것이며 스냅샷별 저장 기록을 하나로 합치는 변경은 아니다. 네트워크 재시도와 중복 방지 정책은 유지한다. 영속 전송 보장은 없으며 페이지 종료, 포화, 실패, 만료 시 기록 일부가 유실될 수 있다.

## 백엔드 처리와 확인

배치 항목 사이 기존 100ms 지연 재접수로 작업자를 양보하고 준비된 스냅샷부터 처리한다. 202는 저장 완료가 아닌 접수다. 큐 64개, 보관 4MiB, 이벤트 128KiB, 만료 30초, 작업자 1개, 집계 60초 정책은 유지한다. 단건 호환 백엔드를 먼저 배포하고 새 확장을 적용한다. 보고 횟수와 드랍, 실패, 대기, 보관량을 함께 확인한다.
