## 현재 상태

SK 템플릿·학력·어학 조건부 규칙은 회사 모듈이 소유한다. 공통 실행부는 정확한 후속 바인딩과 READY 상태를 확인한다. SK 경력 8개 필드는 exact DOM과 프로필 키를 함께 확인하고, ID 없는 재직상태 select도 이름·제어 종류를 검증한 뒤 퇴직사유를 재분석한다. `DERIVED` 대학 날짜는 `YEAR_MONTH`와 반복 행 수·프로필 개수 일치를 사용하며, 국적 lookup은 대한민국으로 한정한다. 후속 반복 버튼의 재식별과 시험·활용능력 개수 분리를 검증했다. 주소 검색은 명시적 capability 협상과 카카오 iframe의 유일 정확 일치 선택을 사용한다.

CF-82는 표준 ID가 전달된 어학 선택에서 현재 보이는 nonzero ID 메뉴 후보가 정확히 하나일 때만 확정한다. 표시 라벨 또는 언어 괄호를 제외한 라벨은 명시적 별칭과만 비교하며, 후보가 없거나 여러 개면 입력하지 않는다. 프로필의 자유 텍스트를 표준 ID로 추측하지 않는다. 이 보완은 [CF-82 근거](../../raw/issues/CF-82/documents/adapter/live-option-selection.md)에 따른다.

이번 후속 매핑은 로컬 정책 v22에 반영된 범위에서 확인했으며 production 정책 배포 완료를 뜻하지 않는다.

학교·자격증·시험 검색은 같은 입력의 jQuery UI widget에서 새 검색 완료와 유일한 label/value를 확인하고, 시험은 nonzero id만 자동 확정한다. 행·검색 종류별 쓰기와 확정은 직렬 처리하며 시험 언어 선택 뒤 하나의 text 또는 select 성적란이 확인될 때만 후속 분석한다. 실제 패널에서 전체 fixture의 시험 2행, 자격증 3행, 대학 1행 선택과 프로필 일치를 확인했고, UI 집계 23개 기입 성공·0개 직접 확인은 전체 항목 성공을 뜻하지 않는다. 미일치 주소 미입력과 공개 주소의 선택·반영, 원래 프로필 복원과 시험 입력 정리를 확인했다. 실제 저장 호환성, 이번 fixture에 포함되지 않은 다른 필드와 전체 취소 UX는 별도 제한으로 남아 있다.

## 변경 이유

회사 규칙을 공통 워크플로에서 분리하고 값 없는 진단 및 후속 입력의 서버 허용 상태를 명확히 했다. 실제 검색에서 확인한 iframe 문서 이동을 같은 프레임의 진행 중 검색에 한해 처리하고 검증 범위를 기록했다.
