## 현재 상태

현대 전용 수집·반복 행·버튼 선택·라벨 보정을 프론트 회사 모듈에서 관리한다. 로컬 정책 v3은 어학·자격증 취득일을 정확한 ID/이름과 제어 타입으로 구분한다. 정책 v4는 국내 주소, 국적1 대한민국, 학력 그룹별 행과 필드를 조건부로 매핑한다.

CF-82는 열린 버튼 메뉴의 현재 visible `data-code` 옵션을 수집해 표준 ID 별칭과 정확히 하나로 일치할 때만 클릭하도록 보완한다. 정적 코드 사전과 첫 후보 추측은 사용하지 않고, 클릭 뒤 표시 라벨과 hidden code를 확인한다. 상세 제한은 [CF-82 근거](../../raw/issues/CF-82/documents/adapter/live-option-selection.md)를 따른다.

## 변경 이유

공통 회사 지식 분리 이후 확인된 취득일의 공통 이름 충돌을 보완하고, 미입력의 원인과 검증 한계를 승인된 근거에 추가했다.

## 반복 행 후속 보완

ID 없는 현대 프로젝트·논문 구조 식별로 준비 단계 차단을 복구하고, 어학시험·활용능력의 개수를 분리했다. 자격증명 직접 매핑과 1→3행 추가·개별 입력·중복 추가 방지 회귀를 확인했다. 학력은 정책 v4에서 필요한 행을 준비하며 해외경험 자동 추가는 미지원이다. 로컬 서버 반영과 실제 페이지 재기입 범위를 구분한다. 상세 근거는 위 Current 문서를 따른다.

## 외국어 선택 보완

검증된 언어·영어시험·등급·활용 언어·회화수준 매핑과 단계별 직접입력 준비를 추가했다. 같은 행·메뉴의 선택과 최종 코드 검증, 선행 선택 재실행 방지 및 실패 시 입력 중단을 유지한다. 작문·독해와 미검증 선택지는 추정하지 않는다. Current 근거에서 지원 범위와 검증 한계를 확인한다.

## 주소·국적·학력 검증

국내 주소는 `postCd` readonly의 유일한 정확 결과만 선택하고, 실패·중복·취소에서는 이번 실행이 연 modal만 닫는다. 국적1은 대한민국 표시명과 hidden `KR`를 확정하며 국적2는 보존한다. 학력은 고교·대학·대학원 순서, 종류 메뉴, 그룹별 `itemGroupId/index/count`를 검증하고 학교 `data-auto-type=school`·전공 `data-auto-type=basic`과 유효 코드를 확인한 뒤 재분석한다.

실제 설치 smoke는 고교·학사 2행을 확인했다. 주소 3값·readonly, 국적1 코드 확정·국적2 불변, 학교 2행의 이름·코드·marker·기간 4필드, 대학 전공 코드·GPA·졸업 코드를 독립 대조했다. API 7회는 HTTP 200/ADAPTER/COMPLETE였고 UI 38/0은 전체 성공이 아니다. 실제 대학원·전문학사·박사와 저장·제출 호환성은 미검증이며 toolbar icon 클릭도 검증하지 않았다.
