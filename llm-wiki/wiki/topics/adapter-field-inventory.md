## 현재 상태

현대·SK 프론트의 구현 기능과 자동 검증 범위를 현황표로 관리한다. 개별 필드 연결은 활성 서버 정책과 DOM 검증을 따르며, 실제 페이지 지원을 추정하지 않는다. 현대 취득일의 ID/이름 구분은 비식별 회귀로 검증했으며 수정 후 실제 재기입은 미검증이다. LG 학교 검색은 이번 변경에서 미구현이다.

## 변경 이유

CF-46의 회사별 분리와 현대 취득일 보완을 자동 검증, 현재 화면 읽기 전용 점검, 수정 후 재기입 미검증으로 구분해 기록했다.

## 반복 행 후속 보완

ID 없는 현대 프로젝트·논문 구조 식별로 준비 단계 차단을 복구하고, 어학시험·활용능력의 개수를 분리했다. 자격증명 직접 매핑과 1→3행 추가·개별 입력·중복 추가 방지 회귀를 확인했다. 학력·해외경험 자동 추가는 미지원이며, 로컬 서버 반영과 실제 페이지 재기입 미검증을 구분한다. 상세 근거는 위 Current 문서를 따른다.

## 외국어 선택 보완

검증된 언어·영어시험·등급·활용 언어·회화수준 매핑과 단계별 직접입력 준비를 추가했다. 같은 행·메뉴의 선택과 최종 코드 검증, 선행 선택 재실행 방지 및 실패 시 입력 중단을 유지한다. 작문·독해와 미검증 선택지는 추정하지 않는다. Current 근거에서 지원 범위와 검증 한계를 확인한다.

## SK 반복 추가·주소 검색 검증

전체 fixture에서 경력1·자격증3·시험1행의 준비와 결과 단계 도달을 확인했다. SK 주소 검색은 기존 API의 지원 협상, 정확한 필드 바인딩과 카카오 iframe의 유일 결과 선택을 사용한다. 공개 주소의 우편번호·기본주소·상세주소 반영 및 readonly 유지, 정확 일치 없는 주소의 미입력과 원복을 실제 패널에서 검증했다. 다른 검색의 이름 텍스트 일치를 선택 코드 확정으로 확대하지 않으며 경력 매핑·대학 날짜 길이·시험 성적 문제는 제한으로 유지한다.
