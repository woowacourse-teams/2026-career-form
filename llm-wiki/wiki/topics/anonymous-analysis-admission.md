## 현재 상태

지원 정보의 로컬 보관과 비회원 이용을 유지하며 통계 및 Push 구독과 분리한 서버 발급 설치 자격을 검증한다. 등록 결과 재전달 10분과 완료 키 기록 24시간은 활성 API 토큰의 수명과 다르다. 로그인이나 실제 사람 인증을 도입한 것으로 해석하지 않는다.

사용자 성공 이용량과 서버 보호용 전송 승인을 분리하고 예약과 집계는 MongoDB의 단일 문서 조건부 변경으로 정산한다. 확실한 미전송은 반환하고 전송 여부 불명은 보호 한도에서 유지한다. 미정산 예약 반환은 AI 요청 재실행이 아니다. 기존 분석 API는 snapshot과 후보 관계 검증까지 통과해야 사용자 예약을 확정한다.

구현과 로컬 자동 검증이 완료된 상태이며 기본 비활성이다. 등록 API 선행 제공 후 분석 자격을 강제하고 운영 TLS, 신뢰 프록시와 키 설정은 사람이 확인한다. 합성 비교는 제한 동작의 검증이며 운영 효과, 실제 비용과 동시 수용량의 근거가 아니다.

## 변경 이유

API 요청 수만 제한하면 정책 처리와 정상 후속 분석을 함께 차단할 수 있다. 익명 설치 자격, 성공 이용량과 전송 자원 보호를 나눠 제품 원칙과 정상 흐름을 유지하고 장애 및 우회 한계를 명시한다.
