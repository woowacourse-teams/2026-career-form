## 현재 상태

랜딩 히어로는 자동 재생 시뮬레이션과 `커리어폼 체험하기` 버튼 하나로 구성하고, 설치 버튼은 헤더·하단 전환 섹션·체험 완료 카드에 둔다. `/try/`는 패널 대기 화면 조사의 가상 지원서와 실제 사이드패널 UI를 설문 없이 재사용해 방문자가 `자동 기입`을 직접 누르게 하며, 완료 카드에서 설치로 잇는다. 누르기 전 자동 기입 버튼을 강조하고, 패널의 프로필 관리·지원 공고 관리는 패널 안 안내 카드로 대신한다. 700px 이하에서는 체험 대신 설치 버튼과 안내를 보여준다. `/tech/`는 자동 기입 칸 연결과 공고 알림 두 주제를 흐름도 3개와 알림 데모로 소개한다. 체험 진입·시작·완료는 `trial_*` 이벤트로 `surface`만 기록한다.

확장 온보딩은 CF-193의 단계형 프로필 등록(한 탭, 시작 목적 선택, 선택 입력과 요약 보충, 저장 성공 후 이동)을 그대로 따른다. 독립 웹 빌드와 가상 데이터 기반 시뮬레이션 경계를 유지하고, 체험과 기술 소개는 프로필을 저장하거나 서버에 요청하지 않는다. 정책 문서는 기존 미시행 초안을 유지하며 사이트 공개 배포는 아직 없다.

## 변경 이유

자동 재생만으로는 제품을 눌러볼 자리가 없었고, 패널 대기 화면 조사에서 직접 체험이 좋은 반응을 얻었다. 설치 전 체험과 기술 소개로 설치 결정과 프로젝트 설명의 근거를 랜딩 안에 둔다.
