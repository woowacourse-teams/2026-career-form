## 현재 상태

랜딩은 히어로 뒤에 의사결정 AI(JEV)가 지원서를 채우는 과정을 7단계 화면 고정 스크롤 장면(자동 기입 누르기와 콘솔 전환, 묶음 나누기, 종류 판단, 후보 좁히기, 확신 재기, 채우기, 확인 요청)으로 보여주고, 바로 아래 10칸 가상 지원서와 간이 패널로 된 직접 체험, 마감 알림 장면(하루 전 알림, 지원 완료 시 남은 알림 취소), 안심 포인트·설치 버튼·FAQ 순서로 둔다. 신뢰도는 확실·애매·모름과 퍼센트로 보인다. 체험은 자동 기입을 누르기 전까지 아래 스크롤을 붙잡고 건너뛰기를 두며, 700px 이하에서는 붙잡지 않고 링크 보내기와 설치 버튼을 보인다. 연출은 미리 렌더한 클레이 webp와 transform/opacity만 쓰고 동작 줄이기 설정에서는 단계가 움직임 없이 바뀐다. 랜딩·기술 소개·정책은 `#B1E5FD` 기반 하늘색 전용 토큰을 쓰고 확장의 `theme.css`는 바꾸지 않는다. 정책의 문의 이메일은 `개설 후 기재`이며, 모든 사이트 페이지는 앵커가 없으면 맨 위에서 열린다.

`/try/`는 CF-363대로 실제 사이드패널 UI로 체험하는 페이지로 남고, 확장 온보딩은 CF-193의 단계형 프로필 등록을 따른다. 체험 시작·완료는 `trial_*` 이벤트로 `surface`만 기록한다. 장면의 분석 시간 수치는 출처 확인이 남아 있다. 독립 웹 빌드와 가상 데이터 경계를 유지하고, 정책 문서는 미시행 초안이며 사이트 공개 배포는 아직 없다.

## 변경 이유

문구와 장식 요소가 많아 핵심이 묻혔고, 의사결정 AI로 빠르고 정확하게 채운다는 점과 체험이 소개 흐름에 드러나지 않았다. 스크롤 장면으로 JEV의 동작을 단계별로 보여준 뒤 같은 지원서에서 바로 눌러보게 해 설치 결정으로 잇는다.
