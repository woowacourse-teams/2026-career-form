## 현재 상태

프로필 탐색과 지원서 패널은 하늘색 바탕, 카라멜 동작 강조, 코코아 계열 텍스트 계층을 공유한다. 이 UI 계층은 저장·승인·쓰기 동작과 분리된다.

## 변경 이유

마스코트의 색감을 반영하되 갈색이 화면을 지배하지 않도록 하고, 일반 확장 화면과 Shadow DOM 패널의 시각적 일관성을 유지한다.
