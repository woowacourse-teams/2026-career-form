## 현재 상태

입력 위치 따라가기를 기본으로 하며 입력 컨트롤만 강조하고 원래 스타일을 복구한다. 결과는 완료, 확인 필요, 실패로 구분하며 미입력 값과 실제 선택지에 접근할 수 있게 한다. 첫 설치에서만 내부 온보딩을 열고 실제 프로필 관리로 연결한다.

## 변경 이유

입력 중인 위치와 남은 확인 항목을 쉽게 찾도록 표현을 정리하고 첫 설치 안내 진입을 연결했다. 기존 입력 판단과 민감값 보호는 유지한다.
