## 현재 상태

자동 기입 중에는 화면을 고정하고, 사용자가 결과 항목 또는 범주를 선택할 때 위치를 안내한다. 확인 필요는 복사·필드 이동과 실패 사유를 제공하고, 입력 완료는 실제 조작한 입력칸을 범주별로 강조한다. 라벨 글자를 피하며 다른 범주 선택 시 이전 강조를 제거한다. 확인했어요는 선택적인 세션 내 접기이며 저장·제출 상태가 아니다. 패널 직접 수정은 제공하지 않는다.

첫 설치에만 내부 온보딩을 열고 프로필 관리로 연결한다. 랜딩은 자동 입력의 가치, 온보딩은 설치부터 남은 값 복사·붙여넣기까지 안내한다. 합성 시연은 실제 프로필과 시스템 클립보드에 접근하지 않는다.

현대·SK 검색 실패는 값 없는 허용 진단 코드만 결과 UI로 전달한다. 검색의 유일한 정확 결과 확인과 지원 범위, 최신 범용 실행의 승인·중단·날짜 변환 경계를 유지한다.

## 변경 이유

입력 중 화면 이동을 줄이고 남은 확인 항목을 쉽게 찾도록 표현을 정리했다. 첫 설치 안내는 실제 사용 순서와 연결했다. 기존 입력 판단과 민감값 보호는 유지한다.
