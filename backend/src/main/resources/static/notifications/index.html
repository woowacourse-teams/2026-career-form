발송 규칙

예정 시각은 등록 시각과 접수 시작 중 늦은 쪽입니다. 수정 기능은 없으며 삭제 후 재등록하면 전원에게 다시 발송됩니다. 서버는 FCM 수락까지만 재시도하고 기기 도착은 확인하지 않습니다.

공고 등록

직무가 하나로 정해지지 않은 공채는 비워 둡니다. 비우면 직무 없이 알림이 나가며, 직무 없는 공고는 새 확장 버전에서만 표시됩니다.

시각은 이 브라우저의 시간대로 해석합니다. 접수 시작이 이미 지난 공고는 다음 발송 주기에 바로 나갑니다.

발송 요약

예정 시각이 기간 안인 발송을 발송 문서에서 집계합니다. 수락률·포기율은 끝난 발송 기준, 평균 시도는 전체 발송 기준이며 지연은 예정 시각에서 FCM 수락까지입니다. 전달 경로나 큐를 바꿀 때 전후 비교의 기준 수치입니다.
